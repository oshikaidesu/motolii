# internal — 作者のメモと調べた記録

*The author's own working notes and research. Nothing here is needed to use, extend or build Motolii. Only the text is in git (about 210 files); the screenshots and films beside it stay on the author's disk, kept out by `.gitignore`, and make the folder over 1 GB there.*

読まなくてよい所です。使う・持ち込む・直すのに要る物は、ここには置きません（[`../README.md`](../README.md) の表）。

git に入っているのは文字だけ（`.md`・`.py`・`.txt` など約 210 本）です。調べた時の画面の写真と動画（`reports/**/*.png`・`.jpg`・`.mp4`・`.gif`・`.webm`、`reports/window/user_panels/` など）は `.gitignore` が外しているので、作者の機械にだけあり、そこでは 1 GB を超えます（多いのは `reports/window/` の `show/`・`screen/`）。調べた記録を新しく置くのはここだけです（AGENTS.md 構成の目標 4）。

| フォルダ | 中身 |
|---|---|
| `notes/` | 作者が今使っているメモ：`TASKS.md`（やること）、`AE_RUBRIC.md`（After Effects と比べる採点表）、`CREATE_PROGRAM.md`（Create と Program の線引き）、`rename_words.md`（身内の言葉を AE などの言葉に替える計画） |
| `notes/tasks_history/` | `TASKS.md` から外した、日ごとの経過の全文（`tasks_log_<日付>.md`） |
| `reports/` | 調べた記録。下のフォルダは、調べた相手の名前 |
| `reports/after_effects/` | After Effects：式（エクスプレッション）の弱み、パネルの言葉、採点の証拠（`ae_rubric/`） |
| `reports/alight_motion/` | Alight Motion：効果とイージングの一覧、画面、出どころ |
| `reports/aviutl/` | AviUtl・AviUtl2：スクリプトのカタログと、そのまま動かすための変換の計画 |
| `reports/capcut/` | CapCut：効果の系統と出どころ、測った値（`capcut_measure/`） |
| `reports/other_apps/` | 1 本で済んだほかのアプリ：Ableton の画面、Blender のアドオンの売り手 |
| `reports/effects/` | 効果の出どころ（ISF・ShaderLab・TSL など）、Web の効果で足りない物、効果の限り |
| `reports/engine/` | 中身の作りを決める前の調べ：要る物、参考のコード、形と絵の変換、3D の文字、試しの脚本（`geonodes_probe/`・`prism_tries/`） |
| `reports/window/` | Motolii の窓：画面・マウス・書き出しの地図、初めての人の操作の記録（`firstclick/`・`firstclick_b/`）、カードの UI、スキンを走らせた記録 |
