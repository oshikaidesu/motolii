# docs — どれを読むか

*Which folder is for whom. The guide is for people making videos; the contributor docs are for people changing the code; `internal/` is the maintainer's own notes and research and can be skipped.*

| 場所 | 誰向け | 中身 |
|---|---|---|
| [`guide/`](guide/) | 使う人 | 画面のタブごとの絵と使い方（[日本語](guide/tabs.md)・[English](guide/tabs.en.md)）。README の頭の 8 秒の作り方（[`readme_movie.md`](guide/readme_movie.md)：貼れば `~/Movies/Motolii/mv.mp4` ができる）。入口はリポジトリの [`README.md`](../README.md) |
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | コードを触る人 | 全体の作り（窓・中身・描画・動画のつながり）。最初に読む |
| [`TESTING.md`](TESTING.md) | コードを触る人 | 試験の決まり |
| [`WINDOWS.md`](WINDOWS.md) | コードを触る人 | Windows で動かすには何が要るか（まだ組んでいない。ソースを読んで分かった事と分からない事） |
| [`app/`](app/) | 窓（Flutter）を触る人 | 窓と中身の境目、見た目の決まり、スキンの作り方。入口は [`app/README.md`](../app/README.md) |
| [`pictures/`](pictures/) | — | README とガイドが載せる絵と動画（画面の写真・作例の gif） |
| [`internal/`](internal/) | 作者だけ（読まなくてよい） | `notes/`：作者のやること・採点表。`reports/`：他のアプリ（After Effects・Alight Motion・CapCut など）を調べた記録 |

手伝い方は [`.github/CONTRIBUTING.md`](../.github/CONTRIBUTING.md)（[English](../.github/CONTRIBUTING.en.md)）。
