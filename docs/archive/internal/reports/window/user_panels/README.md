## 4つの道具に共通する型（穴 → 埋め方）

1. **道具が散らばっている → 手元に集める**
   - Blender：パイメニュー（PME、MACHIN3tools）
   - AE：KBar、Motion Tools
   - Premiere：打って選ぶ命令一覧（Excalibur）
   - いずれもカーソルの横や1本の棚に出す。
2. **言葉で探すのがつらい → 絵から選ぶ**
   - 体の形の絵から骨を選ぶピッカー（Maya、Blender）
   - アンカーを9方向から選ぶ点（AE の LayoutKit+）
   - 暗部・中間・明部の3列のボタン。押すと先にマスクの下見が出る（Lumenzia）
3. **保存して使い回せない → 縮小図の一覧**
   - ポーズ（Studio Library）
   - イージングの曲線（Flow）
   - 保存すると縮小図が自動で付く動き（AE の SaveAnimation、X で 1294いいね）
4. **組み立てが長い → 段取りの順に並べて、1回押すと組み上がる**
   - 段取りの順に並び、用が済むと閉じる（TK9）
   - 押すとレイヤー一式ができる（Infinite Retouch）
5. **足したパネルが増えすぎる → パネルの片付け**
   - Blender の「タブの密林」を片付ける Clean Panels
   - AE のスクリプトをまとめる道具
   - 拡張を足していくと、最後は片付けの道具が要る。

**ほめ言葉**：「一押し」「下見がすぐ出る」「段取りの順」「用が済むと消える」「マウスが減る」「これなしでは無理」「本体に入っていないのが不思議」。見た目の美しさをほめる言葉は、ほとんど出てこない。

**けなし言葉**：「版が上がると壊れる」「自分のキー割り当てとぶつかる」「多すぎて圧倒される」「作者が更新をやめた」。

## Motolii と照らすと

| 型 | Motolii にあるか |
|---|---|
| 1 手元に集める（パイ、命令一覧） | ない |
| 2 絵から選ぶ | Transform、光、カメラのカードの絵で始めている（課題26） |
| 3 縮小図の一覧 | レシピとスクリプト（filament/ways）はあるが、縮小図はない |
| 4 段取りの順に、1回押すと組み上がる | Create 棚のレシピが近い |
| 5 パネルの片付け | Motolii は窓が1つなので、まだ要らない。足せるようにしたら要る |
