## 全体を通して見えたこと

- **形が収束している。** 互いを知らない作者が、同じ形に行き着いている。イージングは曲線と見本の格子、色は文字のない四角の並び、ピッカーは体の形、エフェクトは結果の絵の格子。
- **選ぶものは、その結果の絵で見せる。** 曲線の形、色そのもの、ブラシの絵、飾った文字、そのフォントで書いた名前。文字の名前で選ばせるパネルは、作り直しの中では少数。
- **取っ手には色を付ける。** 曲線の取っ手、左右の骨、まとまりの帯。
- **暗い地に、明るい差し色を少し。** ほぼ全部がそう。
- **売り場の表紙はパネルではなく宣伝の絵。** 本体の画面は、BOOTH や Superhive の2枚目以降に出てくる。

# 3回目：X、Threads、Bluesky を国で分けずにまとめて（2026-10-17）

**やり方**：8つの機能ごとに、各言語の言葉を「または」でつないで1回で検索した。画像付きの投稿だけを拾い、いいね数では絞っていない。
- X：362件。このうち、名前で明らかに無関係と分かるアカウント（AI のニュース、暗号資産、ゲーム会社など）を外した159件を見た。
- Bluesky：151件
- Threads：92件

一覧の画像は ../sheets/sns/。

**結果**：関係のある画像は全体の2〜3割で、ほとんどが1回目と2回目の形の繰り返しだった。SNS からも新しい形は出てこず、飽和が裏付けられた。
- Bluesky は、「pie menu」が食べ物、「palette」が絵の色見本ばかりで、道具を作る人がほとんどいない。

**新しく見えたこと**
- **9点のアンカー格子が、2026年の AE ベータ版に本体の機能として入った**（Quick Set Anchor）。作り直されてきたものが、本体に取り込まれた例になる。
- **同じ形が、映像ソフトの外にも広がっている。**
  - 音のプラグイン（Kickstart 2）も、曲線の形の記号ボタンを1列に並べている。
  - 丸いメニューは、VRChat の表情メニュー、ゲームパッド（reWASD）、ザ・シムズの改造（検索できる丸いメニュー）、Mac の常駐アプリ（Pieoneer）にもある。
- **丸いメニューに入れる記号を、別の人が作って売っている**（VRChat のメニュー用の記号180個、1,364いいね）。丸いメニューという形の上に、さらに飾りの文化ができている。
- AE の中の丸いメニュー（アンカーの中央揃え、レイヤーの移動、コンポの切り抜き、カメラとヌル）。記号と短い名前が、輪の上に並んでいる。
