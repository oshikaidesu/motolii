# Motolii カメラガイド — Boxcam 額縁 × Z 注目 × FPS レーダー

Motolii のカメラは、従来の 3D ソフトのように「レンズ座標と回転 6 自由度を手打ちする」のではなく、**「四角い額縁を被写体に合わせる（Boxcam）」＋「見たい対象を 1 クリックでロックする（Z 注目）」＋「3D で角度を見つけて 1 押しで正対する（Match View）」** という 3 ステップで動かします。

---

## 1. 基本の考え方（4 つの仕組み）

1. **額縁中心モデル（Boxcam 方式）**
   - カメラの `Position (X, Y, Z)` はレンズの位置ではなく、**映す額縁（ピント面）の中心** です。
   - `Distance` で額縁からの引き距離（枠サイズ）、`Rotation Z` でロール、`Rotation X / Y` で額縁を固定したままの斜め回り込みを操作します。`Rotation X / Y = 0°` では 2D モーショングラフィックス向けの素の Boxcam としてそのまま使えます。
   - `Focus Distance = 0` のときは自動ピント（Auto Focus）が働き、常に額縁面（Z 注目中の被写体）へピントが合います。
2. **ライブ追従 Z 注目（`Target`）**
   - レイヤーを 1 クリック（または右クリック → `Focus Camera Here`）すると、カメラの額縁中心がそのレイヤーをリアルタイムに追従します。
   - タイムライン上で `Target` を別レイヤーへ切り替えると、区間イージングに沿って滑らかにカメラが移ります。解除してもカメラは現在位置に留まり、画面がジャンプしません。
3. **瞬間俯瞰 `3D View` と角度正対 `Match View`**
   - 普段の Stage は本番ファインダー（Camera View）に集中します。空間配置を見たいときだけ **`3D View`** を ON にすると、作業カメラがアクティブな額縁の中心を周回し、空間に四角錐のない **純粋な Boxcam 額縁** だけが表示されます。
   - `3D View` で好きな 3D アングルを見つけたら **`Match View`** を 1 クリック。枠サイズ・位置・Z 注目はそのままに、**カメラの角度だけ** が現在の視線にピタッと正対し、再生ヘッド位置にキーフレームが自動記録されます。
4. **FPS レーダー型 Depth パネル**
   - 右下の **Depth** パネルは、ワールド座標に固定された公平な第三者視点（XZ トップビュー）です。
   - シーン内の 3D / 2.5D レイヤーは固定のまま、カメラマーカー・視界コーン（FOV）・被写界深度（DOF）帯・Boxcam 額縁ラインがリアルタイムに動き回ります。

> **Space（`2D` / `2.5D` / `3D`）の使い分け**：
> - **`2D`（カメラ張り付き）**：**2D 背景・テロップ・HUD** 用。3D の深度ソートに参加せずタイムラインの重ね順そのまま（下なら背景、上なら手前）に描かれ、Camera View でも 3D View でも表示中のカメラへ追従し、Depth レーダーの 3D 空間からは除外されます。
> - **`2.5D`（デフォルト・ビルボード）**：ワールド空間の `(X, Y, Z)` に置かれて遠近感・視差を持ちつつ、常にカメラ正面を向きます。
> - **`3D`**：ワールド空間に立体配置され、カメラの回り込みに応じて横や裏からそのまま映ります。

## 2. クイック操作リファレンス

### ショートカット

| キー | 動作 |
|---|---|
| `C` | カメラツールに切り替え |
| `Shift+C` | `3D View`（瞬間俯瞰）の ON / OFF |
| `Option+C` | `Match View`（`3D View` 中、カメラの角度だけ視線に正対＋キーフレーム自動記録） |
| `Escape` | カメラツール中に Z 注目（`Target`）を解除（ジャンプなし） |

### Camera View（通常時）の操作

- **レイヤーをクリック**：Z 注目ロックオン（もう一度クリックで解除）
- **レイヤーを右クリック**：`Focus Camera Here` / `Release Camera Target`
- **ドラッグ**：額縁中心を固定したまま 3D 回り込み（`Rotate X / Y`）
- **`Shift` + ドラッグ**：額縁のパン移動
- **ホイール**：`Distance`（寄り・引き）
- **下部ストリップ**：`Target: <レイヤー名> ×`（解除） / `Flat 0°`（傾きを 0°/0° の平面 Boxcam に戻す）

### `3D View` ON 中の操作

- **背景ドラッグ**：現在の Boxcam 額縁中心を軸に 3D View をオービット回転
- **ホイール**：3D View の寄り・引き
- **額縁の四隅ハンドルをドラッグ**：枠サイズ変更（`Distance`）
- **額縁上辺のロールノブをドラッグ**：カメラのロール回転（`Rotation Z`）
- **額縁の中央ドット（または Select ツールで枠内）をドラッグ**：額縁のパン移動
- **`Match View`（Stage ヘッダー / 下部ストリップ / `Option+C`）**：
  - 傾いて見えている額縁を現在の視線角度に正対させ、再生ヘッドに `Rotate X / Y` キーフレームを自動記録します。
  - 未キーのプロパティに対して `t > 0` で初回実行したときは、`t = 0` の元の角度も自動でキー保持するため、そのままアニメーションが繋がります（`Cmd+Z` 1 回で一括 Undo 可能）。

### Depth パネル（FPS レーダー）の操作

- **レイヤースラブをクリック**：そのレイヤーまでの距離へ手動ピント合わせ
- **ピント破線を視線前後へドラッグ**：`Focus Distance` を調整
- **視界コーン端の丸ノブをドラッグ**：`Focal Length`（画角）を調整
- **右上の `Manual ×` / `On <レイヤー> ×` チップをクリック**：`Focus Distance = 0`（Auto Focus）に戻す

## 3. 30 秒チュートリアル動画の標準フロー（作例構成）

操作解説動画やショートデモを撮る場合、次の 5 カットで全機能が一気に伝わります：

1. **導入（0–5 秒）**：3D 配置した 3 オブジェクト＋2D テロップを Camera View で表示。`C` ツールで被写体 A を 1 クリック → **Z 注目ロックオン**（ロックオンブラケット＋右下の FPS レーダーにリング点灯）。
2. **瞬間俯瞰（5–12 秒）**：`Shift+C` で **`3D View`** ON。四角錐なしの Boxcam 額縁が浮かぶ空間をぐるっとオービット回転（2D テロップが水平追従するのも映る）。
3. **キメ技 `Match View`（12–20 秒）**：タイムラインを 1 秒先へ進めて **`Match View`**（`Option+C`）を 1 押し。斜めに歪んでいた額縁が目の前にピタッと長方形に正対し、同時にタイムラインへキーフレームが打たれ、右下の FPS レーダーの視界コーンがバチッと回転。
4. **本番確認＆DOF（20–28 秒）**：`Shift+C` で Camera View に戻り再生。0 秒→1 秒の滑らかな 3D カメラワーク＋浅い F 値（`f/2.8`）のボケ＋右下レーダーの動きが 3 画面同期で再生される。
5. **ターゲット切替オチ（28–35 秒）**：奥の別オブジェクトをクリックして Z 注目切替 → 自動でピントとカメラが移ってフィニッシュ。
