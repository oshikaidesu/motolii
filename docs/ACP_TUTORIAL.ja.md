# Motolii ACP エージェント活用チュートリアル — シーン丸ごと自動リグ＆演出ワークフロー

Motolii の右パネル（**Agent** タブ）は、ACP（Agent Client Protocol）経由で Claude Code・Codex・Gemini などのコーディングエージェントを直接呼び出せます。
単一レイヤーの式・シェーダーを書くだけでなく、**シーン全体（`scene.json`）と現在の画面プレビュー（`stage.png`）を見て、`ops.json` から複数レイヤーの親子組み・関節ピボット設定・キーフレーム打ち・式の一括適用までを 1 アンドゥで実行**できます。

---

## 1. ACP パネルの仕組み（何が自動で渡るか）

Agent タブでメッセージを送ると、Motolii はリクエスト専用フォルダを作成し、エージェントへ以下を自動添付します（レイヤー未選択でも動作します）：

- **`scene.json`**：プロジェクト全体の状態（解像度・FPS・長さ・`bpm`・`marks`・`isolated_group`・全レイヤーの `id` / `name` / `kind` / `parent` / `order` / `transform` / `anchor` / `size` / `clip` / `fx` 等）
- **`stage.png`**：現在の Stage のレンダリング画像（画像認識できるエージェントはパーツの見た目・位置関係を直接確認可能）
- **選択レイヤーの情報**（選択時のみ）：インスペクターの全カード現在値と、そのレイヤー専用のコードコピー（棚の原本は変更されません）

エージェントが **`ops.json`** を書き出すと、Motolii が即座に全操作を **1 回の Undo ステップ（`Cmd+Z` 1 回で全取り消し可能）** として適用し、`scene.json` と `stage.png` を自動更新します。

> **実装参照**：コンテキスト構築は [`app/lib/workspace/agent/layer_code.dart`](../app/lib/workspace/agent/layer_code.dart)、適用ループは [`app/lib/workspace/agent/agent_pane.dart`](../app/lib/workspace/agent/agent_pane.dart) と [`app/lib/workspace/state/custom_panel_service.dart`](../app/lib/workspace/state/custom_panel_service.dart) にあります。

## 2. チュートリアル 1：PSD キャラの Live2D 風オートリグ

Live2D や After Effects で最も手間がかかる「パーツ配置 → 関節アンカー合わせ → 親子接続 → 揺れもの物理・顔コントローラ構築」を、ACP で一気に自動化する手順です。

### Step 1. パーツ分け PSD をドロップする
1. 部位ごとにレイヤー分けされた `.psd`（または `.psb`）ファイルを Motolii のウィンドウへドラッグ＆ドロップします。
2. Motolii が `psd_sdk` で全ピクセルレイヤーを展開し、**日本語レイヤー名・元キャンバス座標・サイズ比・不透明度・表示状態・クリッピングマスク**を保ったまま、1 つの親 Null グループ配下に配置します（1 Undo）。

### Step 2. 必要なら Group Focus で中央拡大する（プリコンプ風フォーカス）
キャラがシーンの端に置かれていたり、傾いていたり、動く 3D カメラの下にいる場合は、先にフォーカスへ入ります：
- タイムラインで対象グループ（例：`chara` や `頭`）を **ダブルクリック**、または **`Shift+S`**（右クリック → `Enter Group (Focus)`）。
- 対象グループ配下だけが **画面中央・正立・100%・正面フラットカメラ** で表示されます（本編のタイムラインは 1 本のまま、書き出しにも影響しません）。
- この状態で ACP を呼ぶと **`stage.png` も中央に大きく正立したキャラ画像になる** ため、関節や顔パーツの認識精度が上がります。
- 作業が終わったら Stage 上部の **`Exit Focus`**（または `Shift+S`）で本編へ戻ります。

### Step 3. ACP パネルへリグ構築を依頼する
Agent タブでエージェントを選び、例えば次のように指示します：

```text
scene.json と stage.png を見て、chara グループのパーツを Live2D 風にリグして。
1. 見た目位置をずらさずに pivot で関節を設定（頭は首の付け根、前髪・後ろ髪は生え際、腕は肩）
2. 体 → 頭 → 目・口・前髪・後ろ髪 の親子ツリーを parent で接続
3. 頭をゆっくり傾けるサンプルキーフレームを打ち、前髪と後ろ髪に
   layerValue(頭ID, "rotate", t - 0.12) を使った遅延揺れエクスプレッションを付けて
4. 顔向きや瞬きをまとめる Null コントローラも作って、すべて ops.json で 1 アンドゥ適用して
```

### Step 4. 確認とやり直し
- 適用されたらそのまま再生して動きを確認します。
- やり直したいときは **`Cmd+Z` 1 回** でリグ全体が丸ごと元に戻ります。
- 揺れが強すぎる・関節位置を少し下げたいときは、「前髪の揺れを半分にして、頭の pivot をもう少し下（`y: -0.9`）にして」と続けて頼めば、同じセッション内で微調整できます。

## 3. チュートリアル 2：テキスト演出（Texflow / GG 分解）× ACP

1. テキストレイヤーに `Texflow` エフェクトを付け、Inspector カード上で `Bounce` / `Scatter` やベジェ曲線を調整します。
2. 必要なら同カードの **`Split Letters`**（1 文字ごとの編集可能テキスト化）や **`GG Strokes`**（穴抜け保持の輪郭パーツ分解）でパーツ化します。
3. その状態で Agent タブから次のように頼めます：
   - 「`scene.json` の `bpm` と `marks` に合わせて、分解した GG ストロークをビート刻みで登場させて」
   - 「漢字パーツだけ色とスケールを変えて、後ろにアニメーション付きの下敷きマットを敷いて」
   - 「このレイヤーの `texflow.js` を改造して、3D Y軸フリップモードを追加して」

---

## 4. チュートリアル 3：既存エフェクト／式のピンポイント改造

1. 改造したいレイヤーをタイムラインで選択します。
2. Agent タブで「このレイヤーの `Wave` を音声の低音に反応するようにして」「色収差をビート時だけ強めて」と依頼します。
3. Motolii がそのレイヤー専用のコピーを自動生成してからエージェントへ渡すため、**棚の原本や他レイヤーを壊さずに**即座にプレビューへ反映されます。

## 5. ACP エージェントが使う `ops.json` の主要操作

エージェント側が `ops.json` に書き出せる操作（`PanelOp` 共通仕様、詳細は [`shelves/motolii-ui.d.ts`](../shelves/motolii-ui.d.ts)）：

| `op` | 主な用途 |
|---|---|
| `add` | Null（`kind: "shape", file: "null"`）・矩形・テキスト・画像などの新規追加（直後の操作は `layer: -1` で参照可） |
| `psd` | `.psd` / `.psb` を座標・名前付きレイヤー群として展開インポート |
| `pivot` | 見た目の位置を 0px も動かさずに正規化アンカー（`x`, `y` ∈ `-1..1`）を関節位置へ移動 |
| `set` | `parent`・`order`・`clip`・`x/y/z`・`rotate`・`scale_x/y`・`opacity`・`visible` 等の数値設定 |
| `say` | `name`・`fill`・`text`・`split`・`space` 等の文字列設定 |
| `key` | 任意時刻 `at` へキーフレーム打ち（`ease: "Bezier x1 y1 x2 y2"` 等のイージング指定対応） |
| `fx` | 指定レイヤーへ既存または新規作成の `.js` / `.fs` / `.wgsl` を適用 |
| `explode` | テキストを `letters`（文字分解）または `strokes`（GG 輪郭パーツ分解）へ展開 |
| `outline` / `remove` / `select` / `time` | パス変換・レイヤー削除・選択変更・再生ヘッド移動 |

---

## 6. うまく動かすコツ

- **PSD のレイヤー名は意味が分かる名前にする**：`前髪` / `左目` / `頭` / `体` のように付けておくと、`scene.json` だけでエージェントが部位と親子関係をほぼ正確に推定できます。
- **細かい部位は Group Focus してから頼む**：`Shift+S` で対象グループへ入っておくと、エージェントに渡る `stage.png` が見やすくなり、`pivot` 座標やズレの確認精度が上がります。
- **二次揺れ・連動は `layerValue(id, name, t)` を指定する**：Motolii の式は他レイヤーの過去時刻（`t - 0.1` など）を直接読めるため、プロンプトで「`layerValue` で親の過去フレームを参照して遅延揺れを作って」と伝えると素直で軽い式が生成されます。
