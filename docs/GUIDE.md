# Motolii の使い方

ネットで見つけた表現を、そのまま動画に持ち込む。

---

## 1. 開く

アプリを開くとホーム画面が出る。

- **新しく作る** → 「New Project」を押す。空のコンポジション（1920×1080, 60fps, 10秒）が開く。⌘N でも作れる。
- **続きから** → 一番上の「Continue」カードを押すと、前回のプロジェクトがそのまま開く。
- **選んで開く** → プロジェクト一覧からカードを押す。日付順・名前順で並べ替えられる。検索もできる。
- **フォルダを変える** → 「Projects」の横のフォルダアイコンで、一覧の元フォルダを変更できる。
- **ホームに戻る** → ⌘O でいつでもホーム画面を開ける。

プロジェクトは `~/Movies/Motolii/` に自動保存される（トップバーに「Saved 14:30」のように最終保存時刻が出る）。手動で保存する必要はない。

ホーム画面は右上の × で閉じる。

## 2. 画面の構成

```
┌──────────────────────────────────────────────┐
│  トップバー（Undo / Redo / Render / Workspace）│
├────────┬─────────────────────┬───────────────┤
│        │                     │               │
│  棚    │    Stage            │  Inspector    │
│ (Dock) │   （プレビュー）      │               │
│        ├──────────┬──────────┼───────────────┤
│        │          │          │  Camera /     │
│        │ Timeline │   Ease   │  Tool Panel   │
│        │          │          │               │
└────────┴──────────┴──────────┴───────────────┘
```

タブはドラッグで並べ替えられる。トップバーの Workspace 切替で Standard（標準）と Code（コード中心）のレイアウトを選べる。

### 左の棚（Dock）

素材とプリセットを探す場所。タブのアイコンを押して切り替える。

| タブ | 役割 |
|---|---|
| **Media** | プロジェクトフォルダのファイルブラウザ。動画・画像・音声を見つけてレイヤーに取り込む |
| **Effects** | エフェクトの一覧。サムネイルにマウスを乗せるとプレビューが動く。ダブルクリックまたは D&D でレイヤーに適用。Mine フィルターで自分のエフェクトだけ表示。★ でお気に入り・デッキで整理 |
| **Fonts** | フォント一覧。テキストレイヤーのフォントを選ぶ |
| **Colors** | カラーパレット。色を保存・整理できる。選んだ色は Inspector の Fill / Stroke に使われる |
| **Create** | レシピ（テンプレート）と式（エクスプレッション）。レシピはレイヤーと値の一式を作る。式はアニメーションの動きを定義する |
| **Presets** | レイヤーから保存したルック（見た目のプリセット）を再適用する。最初は空で、レイヤーの右クリックメニューから保存すると並ぶ |

### メインエリア

| パネル | 役割 |
|---|---|
| **Stage** | 今のフレームの見た目。レイヤーを直接つかんで位置・大きさ・回転を変えられる。ツールキーで操作を切り替える |
| **Camera View** | Stage の隣のタブ。3D シーンの視点を別角度から確認する |
| **Timeline** | レイヤーの並び・長さ・キーフレーム。バーをドラッグして動かす、端をドラッグして伸縮、フレーム単位でスナップ |
| **Code** | Timeline の隣のタブ。選択レイヤーのエフェクトコードを直接編集する。変更は即プレビューに反映。メタデータ（作者・ライセンス）とタグも表示 |

### 右エリア

| パネル | 役割 |
|---|---|
| **Inspector** | 選んだレイヤーの全値を調整する。値はカードに分かれて並ぶ（下記） |
| **Agent** | AI エージェントにレイヤーのエフェクトコードを書かせるチャットパネル。エージェント一覧から選んでメッセージを送ると、選択レイヤーのコードを読み書きしてくれる |
| **Ease** | キーフレーム間のイージングカーブを編集する。棚からプリセットを選ぶか、カーブを直接いじる |
| **Camera** | 3D カメラの奥行き・視点の操作パネル |
| **Tool Panel** | 選択中のツールに応じた追加コントロール |
| **Blend** | レイヤーの重ね方（ブレンドモード）を設定する |
| **Align** | 選択中のレイヤーの整列・配置 |

### Inspector のカード

Inspector の中はレイヤーの種類に応じたカードに分かれている。各カードはヘッダーを押して折り畳める。

| カード | 中身 |
|---|---|
| **Transform** | 位置(X/Y/Z)・回転・スケール・不透明度。小さなプレビューを直接ドラッグして変形できる。折り畳みの中にアンカーポイント（27 点のボックスで選べる） |
| **Text** | テキストの中身・フォント・サイズ・色・トラッキング・ベースライン。文字を範囲選択して一部だけスタイルを変えられる（AE の Character パネルと同じ） |
| **Fill** | 塗りと線（Stroke を吸収して 1 枚に表示）。単色 / グラデーション。グラデーションを選ぶと Angle・Stretch・Past End が出る |
| **Blending** | ブレンドモード・クリッピング・マット・フェザー。プレビュー付き |
| **Paths** | シェイプのパス編集。ペンツールで描いた点とハンドルを数値で調整 |
| **Media** | 動画レイヤーのフィルムストリップ（サムネイル一覧） |
| **Camera** | カメラレイヤーの焦点距離・位置・回転 |
| **Play** | 再生速度のカーブ（グラフ）。動画レイヤーの速度を変えてスロー/早送りにする |
| **Material** | 3D オブジェクトレイヤー（.glb/.gltf）の質感。金属度・粗さ・反射率・発光などの PBR パラメータ |
| **Keyed** | 動画のクロマキー（緑/青抜き）。背景色を指定して透過にする |
| **Sound** | 音声の値（音量など） |
| **エフェクトカード** | 適用されたエフェクトごとに 1 枚。パラメータを調整。カードの下にメタデータ（作者・ライセンス）とユーザータグのチップが表示される |

## 3. 素材を入れる

### ドラッグ & ドロップ

ファイルをウィンドウに落とすだけ。

| 種類 | 形式 | 結果 |
|---|---|---|
| 動画 | mp4, mov, webm, avi, mkv など | 動画レイヤーになる |
| 画像 | png, jpg, webp, svg, gif など | 画像レイヤーになる |
| 音声 | mp3, wav, aac, ogg, flac など | 音声レイヤーになる |
| Lottie | .json（Lottie形式） | アニメーションレイヤーになる |
| 字幕 | .ass, .srt, .lrc, .vtt | 字幕レイヤーになる |
| 3D | .glb, .gltf | 3D オブジェクトレイヤーになる |

### ⌘V で貼る

**3 種類のものが貼れる：**

1. **ファイル** — Finder でファイルをコピー → ⌘V。D&D と同じ。
2. **スクリーンショット** — ⌘⇧⌃4 で画面を撮って ⌘V。画像レイヤーになる。
3. **コード** — ネットで見つけたコードをコピーして ⌘V。言語は自動判定される。

| 貼れるもの | 元のサイト例 |
|---|---|
| GLSL（Shadertoy） | shadertoy.com |
| GLSL（GLSL Sandbox） | glslsandbox.com |
| GLSL（twigl） | twigl.app |
| ISF | editor.isf.video |
| p5.js | p5js.org/examples |
| three.js（TSL） | threejs.org |
| CSS | — |
| Hydra | hydra.ojack.xyz |

貼ったコードはエフェクトとしてレイヤーに適用される。

## 4. エフェクトを使う

### 棚から選ぶ

左の **Effects** タブを開く。サムネイルにマウスを乗せるとプレビューが動く。

- **ダブルクリック** → 選択中のレイヤーに適用される。レイヤーが無ければ Solid レイヤーが作られてそこに載る。
- **ドラッグ** → プレビュー上のレイヤーに落とすと適用される。
- **検索** → 右上の検索欄で名前を絞り込める。
- **Mine** → 自分で作ったエフェクトだけを表示するフィルター。
- **お気に入り** → ★ を付けて Favorites にまとめられる。デッキとして名前を付けて保存もできる。

### エフェクトの管理

Inspector でエフェクトカードを：
- **並べ替え** — カードのグリップをつかんでドラッグ。順番で結果が変わる。
- **削除** — カードのゴミ箱アイコン、または選んで Delete。
- **on/off** — 目のアイコンで一時的に無効化。

### Create 棚

左の **Create** タブ。レシピ（テンプレート）を選ぶと、レイヤーと値が一式作られる。エフェクトを 1 つ足すのではなく、作品のひな型を置くイメージ。

### Code タブで直接書く

タイムラインの隣の **Code** タブを開くと、レイヤーに適用されているエフェクトのコードが見える。ここで直接編集できる。変更は即座にプレビューに反映される。

コードの下にはメタデータ（作者・ライセンス）とタグが表示される。

## 5. レイヤーを操作する

### 種類

| レイヤーの種類 | 説明 |
|---|---|
| **Video** | 動画ファイル |
| **Image** | 画像ファイル |
| **Text** | テキスト。Inspector の Text カードで編集 |
| **Solid** | 単色の矩形。エフェクトの土台としてよく使う |
| **Shape** | ペンや矩形ツールで描いた図形 |
| **Camera** | 3D シーンのカメラ |
| **Light** | 3D シーンのライト |

### 選択

- **クリック** → レイヤーを選択（タイムラインでもプレビューでも）。
- **Cmd+クリック** → 追加選択 / 解除。
- **Shift+クリック** → 範囲選択（タイムライン）。プレビューでは追加選択。
- **ドラッグ（空き地）** → マーキー選択（プレビュー上）。
- **⌘A** → 全選択。**⌘⇧A** → 全解除。

### 基本操作

| 操作 | ショートカット |
|---|---|
| コピー | ⌘C |
| カット | ⌘X |
| ペースト | ⌘V |
| スタイルをコピー | ⌘⌥C |
| スタイルをペースト | ⌘⌥V |
| 複製 | ⌘D |
| 削除 | Delete |
| リネーム | ⌘R |
| 表示/非表示 | 0（目のアイコンと同じ） |
| ソロ | S（このレイヤーだけ表示） |
| 前面に移動 | ⌘] |
| 背面に移動 | ⌘[ |
| グループ化 | ⌘G |
| グループ解除 | ⌘⇧G |
| キーフレームのあるプロパティだけ表示 | U |


## 6. タイムライン

### 再生

| 操作 | ショートカット |
|---|---|
| 先頭から再生 | Space |
| 今の位置から再生 | Shift+Space |
| 停止 | Space |
| ループ on/off | ⌘L |

### 移動

| 操作 | ショートカット |
|---|---|
| 1 フレーム進む/戻る | , / . |
| 10 フレーム進む/戻る | Shift+, / Shift+. |
| 前/次の停止点 | J / K |
| 先頭 / 末尾 | Home / End |
| ナッジ（選択物を 1F 動かす、無ければフレームステップ） | ← → |
| ナッジ 10F | Shift+← / Shift+→ |

### バーの操作

- **移動**: バーの中をつかんでドラッグ。フレーム単位でスナップする。
- **トリム**: バーの端をドラッグして伸縮。
- **イン点/アウト点をプレイヘッドに合わせる**: [ / ]
- **先頭/末尾をトリム**: ⌥[ / ⌥]
- **分割**: ⌘E（再生ヘッドの位置で分割）。

### ワークエリア

ルーラー下の帯が書き出しと再生の範囲。端をドラッグして変えられる。**⌘⌥B** で選択レイヤーの範囲に合わせる。

### マーカー

タイムラインのルーラーにしるしを打てる。旗のアイコンを押す、またはルーラー上でダブルクリック。

### ズーム

- **タイムラインの拡大/縮小**: = / -
- **選択範囲にズーム**: Z
- **全体を表示**: W
- **元のズームに戻す**: X

## 7. 値を調整する（Inspector）

レイヤーを選ぶと、右の Inspector にそのレイヤーの値が出る。

### 数値

- **スクラブ**: 数字の上で左右にドラッグ。
- **直接入力**: クリックで数字を入力。Return で確定、Escape でキャンセル。
- **細かく**: Shift を押しながらスクラブすると 1/10 の精度。
- **大きく**: Cmd を押しながらスクラブすると 10 倍の刻み。
- **元に戻す**: ダブルクリックでデフォルト値に戻る。
- **右クリック**: 値のメニュー（リセット、コピー、ペースト、キーフレーム操作）。
- **Tab**: 次の値へ。Shift+Tab で前の値へ。

### キーフレーム

- 数字の角のドット ● を押すと、今のフレームにキーフレームが打たれる。
- 別のフレームに移動して値を変えると、その間が自動で補間される。
- **A キー**（Animate）を押すと、値を変えるたびにキーフレームが自動で打たれるモードになる。もう一度押すと解除。

### イージング

キーフレーム間の動き方を Ease パネルで変えられる。棚からプリセット（Linear、Ease In、Ease Out、Bounce など）を選ぶか、カーブを直接いじる。

### メタデータとタグ

エフェクトカードの下に、作者・ライセンスとユーザータグのチップが表示される。＋ボタンでタグを追加（オートコンプリート付き）、×ボタンで削除。

## 8. プレビュー（Stage）

### ツール

| キー | ツール | 操作 |
|---|---|---|
| V | 選択 | レイヤーを選ぶ、ハンドルでリサイズ・回転 |
| M | 移動 | レイヤーをドラッグで移動 |
| R | 矩形 | クリックで矩形シェイプレイヤーを作成 |
| E | 楕円 | クリックで楕円シェイプレイヤーを作成 |
| P | ペン | クリックでパスの点を置いていく |
| T | テキスト | クリックでテキストレイヤーを作成 |
| B | ブラシ | ドラッグで描く |
| C | カメラ | ドラッグで視点を回転（0.25°/px）、ホイールで前後 |

### 操作

- **ズーム**: Cmd + ホイール（ポインタ中心）。
- **パン**: ホイールまたは二本指ドラッグ。
- **全体を表示**: ダブルクリック（空き地）。
- **Shift+ドラッグ**: 比率やアスペクト比を維持。
- **Option+ドラッグ**: 中心から拡縮。

### テキストの編集

テキストレイヤーをダブルクリックするとテキスト入力モードに入る。文字を選択して Inspector の Text カードでフォント・サイズ・色・トラッキング・ベースラインを変えられる。選択した文字だけにスタイルが適用される。

### シェイプの編集

ペンツール（P）で描いた図形は、選択ツール（V）で点をクリックして動かせる。ダブルクリックで新しい点を追加。Delete で点を削除。ハンドルをドラッグしてカーブを変える。

## 9. 書き出す

- **動画**: トップバーの **Render** ボタン、または ⌘⇧R / File > Export Video。設定（解像度、fps）はコンポジション設定に従う。書き出しは mp4。トップバーに進捗が表示される。
- **1 フレーム**: Shift+E / File > Export Frame。今のフレームを画像として書き出す。

書き出した動画の隣に、使ったエフェクトの **クレジットファイル**（作者・ライセンスの一覧）が自動で作られる。動画を公開するときにそのまま使える。

## 10. 右クリックメニュー

どこでも右クリック（または ⋮ ボタン）でその場のメニューが出る。

- **レイヤー**: 削除、複製、リネーム、表示/非表示、ソロ、並べ替え。
- **数値**: リセット、コピー、ペースト、キーフレーム操作。
- **エフェクトカード**: 削除、複製、on/off。
- **タイムラインのバー**: 分割、トリム、複製、削除。

## 11. カスタマイズ

### スキン

View > Skin から見た目を変えられる。`shelves/skins/` のスキンと、自分で作ったスキンが一覧に出る。

### 自分のファイルを追加する

`~/Library/Application Support/Motolii/` の中に自分のファイルを置ける。

| フォルダ | 中身 |
|---|---|
| `effects/` | エフェクト。Effects 棚の Mine フィルターに出る |
| `expressions/` | 式。Create 棚に出る |
| `ease/` | イージングプリセット。Ease 棚に出る |
| `skins/` | スキン。View > Skin に出る |
| `create/` | レシピ。Create 棚に出る |

### キーボードショートカット

`~/.motolii/keybindings.json` でカスタマイズできる。メニューバーの各項目にショートカットが表示されている。

書式: `[{"key": "cmd+shift+z", "command": "edit.redo"}]`。コマンド名の先頭に `-` を付けるとそのキーを外せる。

### Undo / Redo

⌘Z / ⌘⇧Z。すべての操作が 1 ステップずつ戻せる。トップバーの Undo / Redo ボタンには直前のステップの内容が表示される。
