# Motolii の使い方

ネットで見つけた表現を、そのまま動画に持ち込む。

---

## 1. 開く

アプリを開くとホーム画面が出る。

- **新しく作る** → 「New Project」を押す。空のコンポジション（1920×1080, 60fps, 10秒）が開く。
- **続きから** → 一番上の「Continue」カードを押すと、前回のプロジェクトがそのまま開く。
- **選んで開く** → プロジェクト一覧からカードを押す。日付順・名前順で並べ替えられる。検索もできる。
- **フォルダを変える** → 「Projects」の横のフォルダアイコンで、一覧の元フォルダを変更できる。

プロジェクトは `~/Movies/Motolii/` に自動保存される。手動で保存する必要はない。

ホーム画面は右上の × で閉じる。

## 2. 画面の構成

```
┌──────────────────────────────────────────────┐
│  トップバー（Undo / Redo / Render / Workspace）│
├────────┬─────────────────────┬───────────────┤
│        │                     │               │
│  棚    │    Stage            │  Inspector    │
│ (Dock) │   （プレビュー）      │               │
│        ├──────────┬──────────┼───────────────┤
│        │          │          │  Camera /     │
│        │ Timeline │   Ease   │  Tool Panel   │
│        │          │          │               │
└────────┴──────────┴──────────┴───────────────┘
```

タブはドラッグで並べ替えられる。トップバーの Workspace 切替で Standard（標準）と Code（コード中心）のレイアウトを選べる。

### 左の棚（Dock）

素材とプリセットを探す場所。タブのアイコンを押して切り替える。

| タブ | 役割 |
|---|---|
| **Media** | 動画・画像・音声ファイルを探してレイヤーに取り込む |
| **Effects** | エフェクトの一覧。サムネイルにマウスを乗せるとプレビューが動く。ダブルクリックまたは D&D でレイヤーに適用。Mine フィルターで自分のエフェクトだけ表示。お気に入り・デッキで整理 |
| **Fonts** | フォント一覧。テキストレイヤーのフォントを選ぶ |
| **Colors** | カラーパレット。色を保存・整理できる。選んだ色は Inspector の Fill / Stroke に使われる |
| **Create** | レシピ（テンプレート）と式（エクスプレッション）。レシピはレイヤーと値の一式を作る。式はアニメーションの動きを定義する |
| **Presets** | ルック（見た目のプリセット）を探して適用する |

### メインエリア

| パネル | 役割 |
|---|---|
| **Stage** | 今のフレームの見た目。レイヤーを直接つかんで位置・大きさ・回転を変えられる。ツールキー（V / M / R / E / T / C）で操作を切り替える |
| **Camera View** | Stage の隣のタブ。3D シーンの視点を別角度から確認する |
| **Timeline** | レイヤーの並び・長さ・キーフレーム。バーをドラッグして動かす、端をドラッグして伸縮、フレーム単位でスナップ |
| **Code** | Timeline の隣のタブ。選択レイヤーのエフェクトコードを直接編集する。変更は即プレビューに反映。メタデータ（作者・ライセンス）とタグも表示 |

### 右エリア

| パネル | 役割 |
|---|---|
| **Inspector** | 選んだレイヤーの全値（位置・回転・スケール・エフェクトのパラメータ）を調整する。エフェクトはカードとして並び、カードの下にメタデータとタグが表示される |
| **Ease** | キーフレーム間のイージングカーブを編集する。棚からプリセットを選ぶか、カーブを直接いじる |
| **Camera** | 3D カメラの奥行き・視点の操作パネル |
| **Tool Panel** | 選択中のツールに応じた追加コントロール |
| **Blend** | レイヤーの重ね方（ブレンドモード）を設定する |
| **Align** | 選択中のレイヤーの整列・配置 |

## 3. 素材を入れる

### ドラッグ & ドロップ

ファイルをウィンドウに落とすだけ。

| 種類 | 形式 | 結果 |
|---|---|---|
| 動画 | mp4, mov, webm, avi, mkv など | 動画レイヤーになる |
| 画像 | png, jpg, webp, svg, gif など | 画像レイヤーになる |
| 音声 | mp3, wav, aac, ogg, flac など | 音声レイヤーになる |
| Lottie | .json（Lottie形式） | アニメーションレイヤーになる |
| 字幕 | .ass, .srt, .lrc, .vtt | 字幕レイヤーになる |
| 3D | .glb, .gltf | 3D オブジェクトレイヤーになる |

### コードを貼る（⌘V）

**ネットで見つけたコードをコピーして、アプリで ⌘V するだけ。** 言語は自動判定される。

| 貼れるもの | 元のサイト例 |
|---|---|
| GLSL（Shadertoy） | shadertoy.com |
| GLSL（GLSL Sandbox） | glslsandbox.com |
| GLSL（twigl） | twigl.app |
| ISF | editor.isf.video |
| p5.js | p5js.org/examples |
| three.js（TSL） | threejs.org |
| CSS | — |
| Hydra | hydra.ojack.xyz |

貼ったコードはエフェクトとしてレイヤーに適用される。

## 4. エフェクトを使う

### 棚から選ぶ

左の **Effects** タブを開く。サムネイルにマウスを乗せるとプレビューが動く。

- **ダブルクリック** → 選択中のレイヤーに適用される。
- **ドラッグ** → プレビュー上のレイヤーに落とすと適用される。
- **検索** → 右上の検索欄で名前を絞り込める。
- **Mine** → 自分で作ったエフェクトだけを表示するフィルター。
- **お気に入り** → ★ を付けて Favorites にまとめられる。

### Create 棚

左の **Create** タブ。レシピ（テンプレート）を選ぶと、レイヤーと値が一式作られる。エフェクトを 1 つ足すのではなく、作品のひな型を置くイメージ。

### Code タブで直接書く

タイムラインの隣の **Code** タブを開くと、レイヤーに適用されているエフェクトのコードが見える。ここで直接編集できる。変更は即座にプレビューに反映される。

コードの下にはメタデータ（作者・ライセンス）とタグが表示される。

## 5. タイムラインを触る

- **レイヤーの追加**: 素材を D&D、⌘V、Create 棚から。
- **並べ替え**: レイヤーをつかんで上下にドラッグ。
- **長さの変更**: バーの端をドラッグして伸縮。
- **移動**: バーの中をつかんでドラッグ。フレーム単位でスナップする。
- **分割**: 再生ヘッドの位置でレイヤーを分割（メニューまたはショートカット）。
- **削除**: 選んで Delete キー。

### キーフレーム

Inspector の値の横にある ● を押すと、今のフレームにキーフレームが打たれる。別のフレームに移動して値を変えると、その間が補間される。

キーフレーム間のイージングは、Inspector 下部の **Ease** パネルで変えられる。棚から選ぶか、カーブを直接いじる。

## 6. 値を調整する（Inspector）

レイヤーを選ぶと、右の Inspector にそのレイヤーの値が出る。

- **数値を変える**: 数字の上で左右にドラッグ（スクラブ）。クリックで直接入力。
- **細かく**: Shift を押しながらスクラブすると 1/10 の精度。
- **大きく**: Cmd を押しながらスクラブすると 10 倍の刻み。
- **元に戻す**: ダブルクリックでデフォルト値に戻る。
- **右クリック**: 値のメニュー（リセット、コピー、ペースト、キーフレーム操作）。

エフェクトはカードとして並ぶ。カードの下にはメタデータ（作者・ライセンス）とユーザータグが表示される。＋ボタンでタグを追加できる。

## 7. プレビュー

- **再生/停止**: スペースキー。
- **コマ送り**: ← → キー。
- **ズーム**: Cmd + ホイール。
- **パン**: ホイールまたは二本指ドラッグ。
- **カメラ操作**: Camera ツール（C キー）でドラッグすると視点が回る。ホイールで前後。
- **ツール切替**: V（選択）、M（マーカー）、R（矩形）、E（楕円）、T（テキスト）。

## 8. 書き出す

トップバーの **Render** ボタン、または File > Export Video。

設定（解像度、フレームレート）はプロジェクトのコンポジション設定に従う。書き出しは mp4。

書き出した動画の隣に、使ったエフェクトの **クレジットファイル**（作者・ライセンスの一覧）が自動で作られる。動画を公開するときにそのまま使える。

## 9. その他

### スキン

View > Skin から見た目を変えられる。`shelves/skins/` のスキンと、自分で作ったスキンが一覧に出る。

### 自分のエフェクトを追加する

エフェクトのコードを `~/Library/Application Support/Motolii/effects/` に置くと、Effects 棚の **Mine** フィルターに出る。同じように `expressions/`、`ease/`、`skins/` にも自分のファイルを追加できる。

### キーボードショートカット

`~/.motolii/keybindings.json` でカスタマイズできる。メニューバーの各項目にショートカットが表示されている。

### Undo / Redo

Cmd+Z / Cmd+Shift+Z。すべての操作が 1 ステップずつ戻せる。
