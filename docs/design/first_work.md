# 0 から作品を作る

*外の人が Motolii で最初の 1 本を作るまでの手順。理想として先に書き、コードで裏を取る。*

*Motolii は離れていた表現の交差点。来る人はそれぞれ違う道から来る。*

## どこから来た？

Motolii に来る人は一つじゃない。それぞれが持っているもの、期待するもの、最初にやることが違う。

### Shadertoy / GLSL から

**持っているもの:** GLSL のシェーダーコード。Shadertoy や GLSL Sandbox で動くもの。

**最初の一歩:** コードをコピー → Motolii で ⌘V → レイヤーになる。再生すると動く。

**交差点の瞬間:** そのシェーダーを文字の上に重ねたり、動画のエフェクトにしたり、キーフレームでパラメータを動かせる。Shadertoy の中だけでは出来なかったこと。

**入り口に置く tips:**
- `iResolution`, `iTime`, `iMouse` はそのまま動く
- `.fs`（ISF 形式）ならエフェクトフォルダに置くだけで Effects タブに出る
- `.wgsl` も同じ。GLSL → WGSL の変換は Motolii がやる（ISF 経由）

### p5.js / Processing から

**持っているもの:** p5.js のスケッチ。OpenProcessing や自分のサイトで動くもの。

**最初の一歩:** `setup()` と `draw()` のコードをコピー → ⌘V → レイヤーになる。スクラブできる。

**交差点の瞬間:** スケッチが動画のレイヤーになるので、他のレイヤーと重ねられる。スケッチの中の音声反応（`p5.sound`）がタイムライン上の音声レイヤーに繋がる。時間がタイムラインにある：巻き戻しも、任意の秒へのジャンプもできる。

**入り口に置く tips:**
- `loadImage`, `loadSound` はスケッチと同名のフォルダに素材を入れるだけ
- p5.sound の `FFT` と `Amplitude` はそのまま動く（Web Audio 互換）
- `createCapture` は動画レイヤーの映像を受け取る

### After Effects から

**持っているもの:** 式の知識。`thisComp.layer("X").transform.position`、`wiggle`、`ease`。

**最初の一歩:** Create → Expression で式カードを追加。`{ x: index * 10, rotate: time * 90 }` と書くだけでコピーが並んで回る。

**交差点の瞬間:** AE の式に Shadertoy のエフェクトを重ねる。CSS の @keyframes でテキストの登場を決めて、AE 式でコピーの配置を決める。別の世界のコードが同じレイヤーの上で共存する。

**入り口に置く tips:**
- `index`, `count`, `time`, `value` — Cavalry と同じ名前。AE の `thisLayer.index` は `index`（0始まり）
- `AE.compile` / `AE.run` で lottie-web が式を解釈する（AE の式がそのまま動く）
- `effect("Name")("Slider")` で式カードのスライダーを読める
- `sampleImage` で他のレイヤーのピクセルを読める
- `each()` で包まなくても、オブジェクトリテラルだけで動く

### AviUtl から

**持っているもの:** `.anm2` / `.obj2` スクリプト。Lua で書かれた表現。

**最初の一歩:** スクリプトファイルを `shelves/aviutl_scripts/` に置く → Effects タブに出る。

**交差点の瞬間:** AviUtl のスクリプトと Shadertoy のシェーダーを同じレイヤーに掛けられる。AviUtl の中では GLSL と Lua は別の世界だった。

**入り口に置く tips:**
- `obj` の呼び出しはエンジンが受ける（LuaJIT で実行）
- HLSL を含むスクリプトは glslang → SPIR-V → WGSL に変換される
- 180 本の AviUtl スクリプトが同梱されている

### CSS / Web アニメーションから

**持っているもの:** `@keyframes`、`transition`、`cubic-bezier`。Splitting.js で文字を動かした経験。

**最初の一歩:** テキストレイヤーを選んで、CSS をコピー → ⌘V → 文字が動く。

**交差点の瞬間:** CSS のレイアウト（flex, grid）で文字を並べて、AE 式で登場タイミングを決めて、シェーダーで光らせる。ブラウザの中では別々だった CSS と WebGL が、一つのテキストの上で合流する。

**入り口に置く tips:**
- `--char-index` と `--char-total`（Splitting.js）がそのまま使える
- Stylo（Firefox の CSS エンジン）が `@keyframes` を解釈する。ブラウザと同じ結果になる
- CSS アニメーション付き SVG（ローダーなど）もそのまま動く
- `cubic-bezier` の精度は Chrome と 0.036 px 以内

### three.js / TSL から

**持っているもの:** three.js のマテリアルコード。TSL ノード。

**最初の一歩:** TSL マテリアルのコードをコピー → ⌘V → 棚のエフェクトになる。

**交差点の瞬間:** three.js のマテリアルが動画のエフェクトとして使える。`WGSLNodeBuilder` が WGSL を生成し、Filament が描く。three.js のデモを動画の中で使える。

**入り口に置く tips:**
- `NodeMaterial`, `colorNode`, `positionNode` を含むコードは自動判定される
- WGSL は three.js 自身の `WGSLNodeBuilder` が生成する（Motolii の変換ではない）
- `shelves/solids/` に three.js の `BufferGeometry` を置くと 3D モデルにもなる

### Cavalry から

**持っているもの:** Cavalry の JavaScript 式。`index`, `count` で書いたコード。

**最初の一歩:** 式をそのままコピー → Motolii の式カードに貼る。`index` と `count` はそのまま動く。

**交差点の瞬間:** Cavalry の式の上に Shadertoy のエフェクトを載せられる。Cavalry には無い映像素材や音声反応と組み合わせられる。

**入り口に置く tips:**
- `index`, `count`, `time`, `value` — Cavalry と同じ名前
- `each()` で包んでも、オブジェクトリテラルだけでもいい
- Cavalry の `random()`, `animate()` に相当するプレリュードが読み込まれる

### Hydra / ライブコーディングから

**持っているもの:** Hydra のコード。`osc()`, `.out()` で書いたビジュアル。

**最初の一歩:** コードをコピー → ⌘V → レイヤーになる。

**交差点の瞬間:** ライブコーディングの映像がタイムラインに載る。時間を戻せる。他のエフェクトと重ねられる。

### GLSL Sandbox / twigl / Bonzomatic から

**持っているもの:** ミニマルな fragment shader。

**最初の一歩:** コードをコピー → ⌘V → エフェクトまたはレイヤーになる。`gl_FragColor` や `fGlobalTime` は自動判定。

**交差点の瞬間:** Bonzomatic のライブシェーダーを動画に焼ける。twigl の 280 文字シェーダーをテキストの背景にできる。

### Paper.js / Two.js / Canvas 2D から

**持っているもの:** 2D 描画コード。`path`, `shape`, `getContext('2d')`。

**最初の一歩:** コードをコピー → ⌘V → レイヤーになる。

**交差点の瞬間:** Paper.js の生成アートをキーフレームで動かしたり、AE 式と組み合わせたり。

### Dwitter / tixy.land から

**持っているもの:** 超短いコード。Dwitter の `d/XXXX` や tixy の `(t,i,x,y) =>` 式。

**最初の一歩:** コードをコピー → ⌘V → レイヤーになる。

**交差点の瞬間:** 140 文字のコードが動画のレイヤーに。タイムラインでスクラブできて、他のレイヤーと重ねられる。

### Turtletoy から

**持っているもの:** Turtle graphics のコード。

**最初の一歩:** コードをコピー → ⌘V → レイヤーになる。

**交差点の瞬間:** 亀の描画がベクターとして動画に入る。

### アニメーション SVG から

**持っているもの:** CSS @keyframes で動く SVG（ローダー、アイコン、svg-spinners など）。

**最初の一歩:** SVG をコピー → ⌘V → 画像レイヤーとして動く。

**交差点の瞬間:** SVG スピナーが動画の素材になる。CSS アニメーションの精度は Chrome と 0.036 px 以内。

### 字幕 (ASS / SRT / LRC / VTT) から

**持っているもの:** タイミング付きの歌詞やテロップ。Aegisub で作った ASS、YouTube の SRT。

**最初の一歩:** ファイルを D&D → 字幕レイヤーになる。`\k` タグのカラオケもそのまま。

**交差点の瞬間:** 字幕の上にエフェクトを掛けられる。libass がレンダリングするのでタグの解釈は正確。

### Lottie から

**持っているもの:** Bodymovin で書き出した Lottie JSON。式入りも。

**最初の一歩:** .json ファイルを D&D → ThorVG がアニメーション再生する。

**交差点の瞬間:** Lottie アニメーションが他のレイヤーと重なる。Lottie の式は lottie-web が解釈する（AE と同じランタイム）。

### ISF / WGSL ファイルから

**持っているもの:** ISF (.fs) や WGSL (.wgsl) のシェーダーファイル。

**最初の一歩:** ファイルを `shelves/effects/` に置く → 再起動不要で Effects タブに出る。

**交差点の瞬間:** 自分で書いたシェーダーが、他の全ての表現と重ねられるエフェクトになる。サムネイルも自動生成される。

### 初めて動画を作る人

**持っているもの:** 動画にしたい素材（写真、動画、音楽）。コードは書かない。

**最初の一歩:** 素材を D&D → テキストを追加 → Effects タブからエフェクトを選ぶ（動くサムネイルで確認） → Render。

**交差点の瞬間:** Effects タブに並ぶエフェクトの一つ一つが、Shadertoy や ISF や AviUtl の世界から来たもの。自分はコードを書かないけれど、世界中のクリエイターの表現を使える。

**入り口に置く tips:**
- エフェクトのサムネイルにポインタを乗せると動いて見える
- スライダーだけで調整できる。コードは見なくていい
- Create タブの Expression タイルも同じ — 押すだけで文字が動き出す

## シナリオ: 30 秒のリリックビデオを作る

曲がある。歌詞がある。30 秒を 1 本の映像にする。

### 1. 開く → 形を決める

Motolii を起動 → Home → **[+ New Project]**。

- 縦横: **9:16**（スマホ向けのショート）
- 解像度: **1080p**
- フレームレート: **30**
- 背景: **黒**

空のステージとタイムラインが出る。

### 2. 曲を入れる

音声ファイル（mp3/wav）を Finder からタイムラインへ **D&D**。

- 波形がタイムラインに出る
- 再生すると鳴る
- プロジェクトの長さが曲に合う

### 3. 歌詞を入れる

**Create → Text** でテキストレイヤーを作る。

- ステージ上でダブルクリック → 歌詞を打つ
- **Fonts タブ** で書体を選ぶ
- インスペクタで **サイズ** を合わせる（0.1 〜 0.3 くらい）
- **Split → Letters** で文字ごとに分ける

1 行ごとにレイヤーを作ってタイムライン上で時間をずらすか、1 つのテキストに全行入れて Split → Lines で行ごとに分ける。

### 4. 文字を動かす

テキストレイヤーを選んで **Create → Expression** から:

- **fade_in** — 文字が 1 つずつ現れる。Delay スライダーで間隔を調整
- **wave** — 文字が波打つ
- **lyric** — 歌詞モーション向け

または直接書く:

```js
{ y: -0.05, opacity: 0, rotate: -5 }
```

↑ 全コピーが少し上に、透明に、傾いた状態。キーフレームで 0 → 1 に戻すと登場になる。

### 5. 色を決める

テキストレイヤーを選んで **Colors タブ**:

- 色の輪で選ぶか、**Sample** で画面から拾う
- **Gradient** にすると文字がグラデーションになる
- 背景を変えるにはレイヤー 0（Composition）を選んで Background

### 6. エフェクトを掛ける

テキストレイヤーに **Effects タブ** から:

- **Glow** — 文字が光る。Amount スライダーで強さ
- **rgbshift** — 色ずれ。画面全体のレイヤー（Adjustment）に掛けるとフィルム感

Shadertoy のシェーダーを ⌘V で貼ってエフェクトにすることもできる。

### 7. 音に合わせる（任意）

式カードで音のレイヤーを読む:

```js
function each(index, count, time, value) {
  const freq = new Float32Array(64);
  getByteFrequencyData(k.js_sound, freq, time);
  const band = freq[Math.floor(index / count * 64)] / 255;
  return { size: 1 + band * 0.3 };
}
```

↑ 文字が音の周波数に合わせて大きくなる。`--sound@sound:Sound` ヘッダでレイヤーを繋ぐ。

### 8. タイミングを合う

- 各テキストレイヤーの **開始点** をタイムライン上で歌詞のタイミングに合わせる
- **Animate** を有効にして、再生ヘッドを動かしながら値を変える → キーフレーム
- キーフレームを選んで **イージング** を変える（カーブエディタ）

### 9. 書き出す

ヘッダの **Render** → 名前と場所を選ぶ → **MP4** → 書き出し。

30 秒 × 1080p なら数十秒で終わる。終わったら Finder で開ける。

### 完成

```
曲 D&D → テキスト → Split → Expression → 色 → エフェクト → タイミング → Render
```

コードを 1 行も書かなくてもできる。書けばもっと細かくできる。ネットのシェーダーを貼ればもっと派手にできる。全部同じタイムライン。

## シナリオ: Code タブから始める

コードを書く人の入り口。Shadertoy のシェーダーを貼る人も、式を自分で書く人も、ここから。

### 1. Code タブを開く

左のタブから **Code** (`</>` アイコン) を選ぶ。

ここには:
- 過去に貼ったコード（自動で棚に保存されたもの）
- 棚の式ファイル（`shelves/expressions/`）

タイルにポインタを乗せると動くサムネイルが出る。ここはエフェクトと同じ。

### 2. ネットのコードを貼る

Shadertoy でシェーダーのコードをコピー → Motolii で **⌘V**。

何が起きるか:
- 言語が自動判定される（`mainImage` → Shadertoy、`setup()`/`draw()` → p5.js、`@keyframes` → CSS、...）
- コードが棚に保存される（`.js`、`.fs`、`.css` として）
- レイヤーまたはエフェクトになる

| 貼ったもの | 判定 | なるもの |
|---|---|---|
| Shadertoy のコード | `mainImage` を検出 | シェーダーレイヤー（ISF 経由で WGSL） |
| p5.js のスケッチ | `setup`/`draw` + `createCanvas` を検出 | スケッチレイヤー |
| CSS @keyframes | `@keyframes` を検出、テキスト選択中 | テキストの文字が動く |
| AE 式 | `AE.compile` または `function each` を検出 | 式カード |
| three.js TSL | `NodeMaterial`/`colorNode` を検出 | 棚のエフェクト（WGSL） |
| Hydra | `.out()` を検出 | シェーダーレイヤー |
| 生のオブジェクトリテラル | `{ x: index * 10 }` | 式カード（each() に包まれる） |

### 3. コードを編集する

Code タブでタイルの **`</>`** を押すとコードが開く。

- 書き換えると**プレビューがすぐ追いかける**（保存不要）
- スライダーがコードの中の数値から自動で作られる
- シンタックスハイライト付き

### 4. 自分で式を書く

テキストレイヤーを選んで、Code タブの入力欄に直接書く:

```js
{ x: index * 0.1, y: Math.sin(time + index) * 0.05, opacity: 1 - index / count }
```

Enter で適用。`each()` で包まなくていい。

もっと複雑なら:

```js
const f = AE.compile(`ease(time, 0, 1, 0, 1) * effect("Amount")("Slider")`);
function each(index, count, time, value) {
  const delay = index / count * 0.5;
  const t = Math.max(0, time - delay);
  return { y: -0.1 * (1 - AE.run(f, { time: t })), opacity: AE.run(f, { time: t }) };
}
```

AE の式がそのまま使える。`effect("Name")("Slider")` でカードのスライダーを読める。

### 5. AI エージェントに頼む

Agent パネルで:

> 「この文字を 1 文字ずつ下から跳ねて登場させて」

エージェントが式を書く。Code タブにコードが現れ、プレビューが動く。気に入らなければ:

> 「もっとゆっくり、バウンスを柔らかく」

同じコードが書き換わる。スライダーで済むことは LLM を呼ばない。

### 6. エフェクトとして保存する

書いたコードが気に入ったら:
- `shelves/expressions/` にファイルとして保存 → 次から Expression タイルに出る
- `.wgsl` を `shelves/effects/` に置けば Effects タイルに出る

コードがファイルだから、Git で管理できるし、人に渡せる。

### 完成

```
Code タブ → ⌘V (or 直接書く) → プレビューで確認 → 調整 → Render
```

ビジュアルのシナリオと同じタイムラインに合流する。Code タブから始めても Effects タブから始めても、最後は同じ Render ボタン。

## リファレンス: 各ステップの詳細

## 開く

Motolii を起動するとホーム画面が出る。前に作ったプロジェクトがサムネイルで並び、「続きから」で大きく出る。初めての人には何も無い。

**[+ New Project]** を押す。

## 形を決める

新しいプロジェクトの形:

| 選ぶもの | 選択肢 | 迷ったら |
|---|---|---|
| 縦横 | 16:9（横）、9:16（縦）、4:5、1:1、4:3 | SNS のショート → 9:16、YouTube → 16:9 |
| 解像度 | 2160p 〜 270p | 1080p |
| フレームレート | 12 〜 60 | 30 |
| 背景色 | 黒・白・灰・緑・青・透明 | 黒 |
| 新レイヤーの長さ | 0 〜 60 秒 / End（プロジェクトの終わりまで） | 5 秒 |

押した瞬間にプロジェクトが開く。空のタイムラインとステージ。

## 素材を入れる

やり方は 3 つ。どれでも同じ結果になる:

1. **Finder からドラッグ & ドロップ** — ステージかタイムラインへ落とす
2. **⌘V** — クリップボードの画像・ファイルを貼る
3. **Media タブ** — 左の Media から選んで Place

### 何を入れられる？（辞書）

| 種類 | 形式 | 入れた後 |
|---|---|---|
| 動画 | mp4, mov, webm, ... (GStreamer が読める物) | 映像レイヤー。音も鳴る |
| 画像 | png, jpg, svg, gif, webp | 画像レイヤー |
| 音声 | mp3, wav, aac, flac, ogg | 音声レイヤー（タイムラインに波形） |
| フォント | ttf, otf | Fonts タブに追加 |
| コード | .js, .css, .wgsl, .fs, .svg (アニメ), .anm2 | 言語を判定して適切なレイヤーかエフェクトへ |
| Lottie | .json (Lottie) | ThorVG で再生 |

複数ファイルを一度に落とせる。落とした位置・時刻にレイヤーができる。読めないファイルは理由が出る。1 回の取り消しで戻る。

## 文字を入れる

**Create タブ → Text** で文字レイヤーを作る。ステージ上でダブルクリックして編集。

- **Fonts タブ** で書体を選ぶ。Mac に入っている書体と、プロジェクトフォルダに置いた書体。
- インスペクタのカードで**サイズ・色・間隔・配置**を変える。
- **Split** で文字ごと・単語ごと・行ごとに分けると、1 文字ずつ動かせる。

## 色を決める

**Colors タブ** を開く。

| やること | 操作 |
|---|---|
| レイヤーの色を変える | レイヤーを選んで、色の輪かパレットから |
| 塗りの種類 | Solid（単色）、Gradient（グラデーション）、None |
| 画面から色を取る | Sample（Mac のスポイト） |
| 使った色を保存 | Keep |
| 写真から色を取る | Media で写真を選んで Photo |

### 未決: カラーパレットの読み込み

- 外部のカラーパレット（.ase, .aco, Coolors の URL, ...）を突っ込むには？
- LLM エージェントに「この動画に合う色を 5 色選んで」と頼めるか？
- 答えはまだ無い。

## 動きを付ける

### エフェクトを掛ける

**Effects タブ** を開く。タイルにポインタを乗せると**動くサムネイル**が出る。レイヤーを選んでタイルを押し、**Add**。

エフェクトはレイヤーのカードに載る。カードのスライダーで調整。

### 式カードを使う

**Create タブ → Expression** のタイルも同じ。`fade_in`、`wave`、`lyric` など。

式カードはコピーの動きを決める:

```js
{ x: index * 10, rotate: time * 90 }
```

↑ これだけでコピーが並んで回る。`each()` で包まなくてもいい。

### 手で動かす

- インスペクタで**値を打つ**
- ステージ上で**ドラッグ**
- タイムラインで **Animate** を有効にして、再生ヘッドを動かしてから値を変える → キーフレーム

### ネットのコードを貼る

**⌘V** でコードを貼る。

- Shadertoy のシェーダー → エフェクトになる
- p5.js のスケッチ → レイヤーになる
- CSS の `@keyframes` → テキストの文字が動く
- three.js の TSL マテリアル → 棚のエフェクトになる

Code タブの `</>` でコードが出て、書き換えるとプレビューがすぐ追いかける。

## 音に合わせる

音声・動画レイヤーの音にエフェクトや式を反応させる。

### 入り口

- **式カードの `--sound@` ヘッダ** — 式が聞くレイヤーを選ぶ
- `getByteFrequencyData`, `getFloatFrequencyData`, `getFloatTimeDomainData` — Web Audio の名前がそのまま使える
- p5.js のスケッチは `p5.sound` の `FFT` と `Amplitude` がそのまま動く

## 調整する

| やること | 操作 |
|---|---|
| キーフレームの間隔 | タイムラインでキーフレームをドラッグ |
| イージング | グラフエディタでカーブを変える |
| レイヤーの順序 | タイムラインでドラッグ |
| エフェクトの順序 | インスペクタでカードをドラッグ |
| 取り消し | ⌘Z（何回でも） |
| やり直し | ⇧⌘Z |

## 書き出す

ヘッダの **Render** ボタンを押す。

| 選ぶもの | 選択肢 |
|---|---|
| 名前と場所 | Finder のダイアログ |
| 形式 | MP4、HEVC、GIF、PNG 連番、JPEG 連番 |
| 解像度 | プロジェクトと同じか変える |
| 品質 | Low 〜 High |
| Motion blur | On / Off |
| 全体かワークエリアか | 選べる |

進み具合と残り時間が見える。終わったら Finder で開ける。

## まとめ: 0 から完成まで

```
開く → 形を決める → 素材を入れる → 文字を入れる → 色を決める
  → 動きを付ける → 音に合わせる → 調整する → 書き出す
```

順番は自由。素材から始めても、文字から始めても、エフェクトから始めてもいい。どの時点でも Render で今の状態を書き出せる。
