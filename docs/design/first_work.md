# 0 から作品を作る

*外の人が Motolii で最初の 1 本を作るまでの手順。理想として先に書き、コードで裏を取る。*

## 開く

Motolii を起動するとホーム画面が出る。前に作ったプロジェクトがサムネイルで並び、「続きから」で大きく出る。初めての人には何も無い。

**[+ New Project]** を押す。

## 形を決める

新しいプロジェクトの形:

| 選ぶもの | 選択肢 | 迷ったら |
|---|---|---|
| 縦横 | 16:9（横）、9:16（縦）、4:5、1:1、4:3 | SNS のショート → 9:16、YouTube → 16:9 |
| 解像度 | 2160p 〜 270p | 1080p |
| フレームレート | 12 〜 60 | 30 |
| 背景色 | 黒・白・灰・緑・青・透明 | 黒 |
| 新レイヤーの長さ | 0 〜 60 秒 / End（プロジェクトの終わりまで） | 5 秒 |

押した瞬間にプロジェクトが開く。空のタイムラインとステージ。

## 素材を入れる

やり方は 3 つ。どれでも同じ結果になる:

1. **Finder からドラッグ & ドロップ** — ステージかタイムラインへ落とす
2. **⌘V** — クリップボードの画像・ファイルを貼る
3. **Media タブ** — 左の Media から選んで Place

### 何を入れられる？（辞書）

| 種類 | 形式 | 入れた後 |
|---|---|---|
| 動画 | mp4, mov, webm, ... (GStreamer が読める物) | 映像レイヤー。音も鳴る |
| 画像 | png, jpg, svg, gif, webp | 画像レイヤー |
| 音声 | mp3, wav, aac, flac, ogg | 音声レイヤー（タイムラインに波形） |
| フォント | ttf, otf | Fonts タブに追加 |
| コード | .js, .css, .wgsl, .fs, .svg (アニメ), .anm2 | 言語を判定して適切なレイヤーかエフェクトへ |
| Lottie | .json (Lottie) | ThorVG で再生 |

複数ファイルを一度に落とせる。落とした位置・時刻にレイヤーができる。読めないファイルは理由が出る。1 回の取り消しで戻る。

## 文字を入れる

**Create タブ → Text** で文字レイヤーを作る。ステージ上でダブルクリックして編集。

- **Fonts タブ** で書体を選ぶ。Mac に入っている書体と、プロジェクトフォルダに置いた書体。
- インスペクタのカードで**サイズ・色・間隔・配置**を変える。
- **Split** で文字ごと・単語ごと・行ごとに分けると、1 文字ずつ動かせる。

## 色を決める

**Colors タブ** を開く。

| やること | 操作 |
|---|---|
| レイヤーの色を変える | レイヤーを選んで、色の輪かパレットから |
| 塗りの種類 | Solid（単色）、Gradient（グラデーション）、None |
| 画面から色を取る | Sample（Mac のスポイト） |
| 使った色を保存 | Keep |
| 写真から色を取る | Media で写真を選んで Photo |

## 動きを付ける

### エフェクトを掛ける

**Effects タブ** を開く。タイルにポインタを乗せると**動くサムネイル**が出る。レイヤーを選んでタイルを押し、**Add**。

エフェクトはレイヤーのカードに載る。カードのスライダーで調整。

### 式カードを使う

**Create タブ → Expression** のタイルも同じ。`fade_in`、`wave`、`lyric` など。

式カードはコピーの動きを決める:

```js
{ x: index * 10, rotate: time * 90 }
```

↑ これだけでコピーが並んで回る。`each()` で包まなくてもいい。

### 手で動かす

- インスペクタで**値を打つ**
- ステージ上で**ドラッグ**
- タイムラインで **Animate** を有効にして、再生ヘッドを動かしてから値を変える → キーフレーム

### ネットのコードを貼る

**⌘V** でコードを貼る。

- Shadertoy のシェーダー → エフェクトになる
- p5.js のスケッチ → レイヤーになる
- CSS の `@keyframes` → テキストの文字が動く
- three.js の TSL マテリアル → 棚のエフェクトになる

Code タブの `</>` でコードが出て、書き換えるとプレビューがすぐ追いかける。

## 音に合わせる

音声・動画レイヤーの音にエフェクトや式を反応させる。

### 入り口

- **式カードの `--sound@` ヘッダ** — 式が聞くレイヤーを選ぶ
- `getByteFrequencyData`, `getFloatFrequencyData`, `getFloatTimeDomainData` — Web Audio の名前がそのまま使える
- p5.js のスケッチは `p5.sound` の `FFT` と `Amplitude` がそのまま動く

## 調整する

| やること | 操作 |
|---|---|
| キーフレームの間隔 | タイムラインでキーフレームをドラッグ |
| イージング | グラフエディタでカーブを変える |
| レイヤーの順序 | タイムラインでドラッグ |
| エフェクトの順序 | インスペクタでカードをドラッグ |
| 取り消し | ⌘Z（何回でも） |
| やり直し | ⇧⌘Z |

## 書き出す

ヘッダの **Render** ボタンを押す。

| 選ぶもの | 選択肢 |
|---|---|
| 名前と場所 | Finder のダイアログ |
| 形式 | MP4、HEVC、GIF、PNG 連番、JPEG 連番 |
| 解像度 | プロジェクトと同じか変える |
| 品質 | Low 〜 High |
| Motion blur | On / Off |
| 全体かワークエリアか | 選べる |

進み具合と残り時間が見える。終わったら Finder で開ける。

## まとめ: 0 から完成まで

```
開く → 形を決める → 素材を入れる → 文字を入れる → 色を決める
  → 動きを付ける → 音に合わせる → 調整する → 書き出す
```

順番は自由。素材から始めても、文字から始めても、エフェクトから始めてもいい。どの時点でも Render で今の状態を書き出せる。
