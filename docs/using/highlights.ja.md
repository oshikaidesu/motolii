# Motolii の特長

[English](highlights.md)

Motolii は、MV やモーショングラフィックスを作るためのオープンソースの動画編集ソフトです。ネットで見つけた表現を、プラグインが作られるのを待たずに、すぐ自分の映像に使えることを目指しています。

このページは、いま Motolii でできて、他では手に入れにくいことと、それぞれの限界をまとめたものです。他の編集ソフトとの比較は[ガイド](guide.ja.md#他のソフトとの違い)にあります。まだ整っていないことは[試す前に](#試す前に)にあります。

## シェーダーのファイルをフォルダに置くだけで使える

ISF（`.fs`）と WGSL（`.wgsl`）のファイルは、エフェクトのフォルダに置くと、アプリを再起動せずにエフェクト一覧に出ます。タイルには、そのエフェクト自身の動く絵が付きます。インストールも変換も要りません。

棚にはすでに、`.fs` が420本、`.wgsl` が266本あります。自分のファイルの足し方は [shelves/README.md](../../shelves/README.md) にあります。

限界：ISF は VJ ソフトも読む公開の形式です。新しいのは、タイムラインと MP4 の書き出しを持つ編集ソフトの中で使えることです。対応形式のファイルでも、すべてが正しく動くわけではありません。

## エフェクトは全部ファイル

ぼかし、ドロップシャドウ、デュオトーン、グラデーションマップも、ほかと同じ棚のファイルです。エフェクト一覧に、アプリに組み込まれた物はありません。置いたファイルは、これらと同じ扱いで、どれも開いて作りを見ることも、写して直すこともできます。

## クリエイティブコーディングのコードを貼ると、レイヤーになる

スケッチを貼ると、Motolii がどのサイトのコードかを見分けます。Shadertoy、GLSL Sandbox、Hydra、three.js、Two.js、Turtletoy、Paper.js、canvas、Bonzomatic、twigl、Dwitter、tixy を読み、それ以外は p5.js として扱います。p5.js はブラウザなしで動き、コードはレイヤーの上で編集できます。

p5.js では、描画の行ごとに 0 から 1 の強さのスライダーが付き、キーフレームも打てます。

限界：貼った作品が正しく動かない、または動かないことがあります。測った数と知っている不具合は[仕様](specifications.ja.md#対応形式と動作状況)にあります。棚の作品の多くは非営利のライセンスです。公開する物のライセンスを確かめてください。

## Mac で AviUtl2 のスクリプトを動かす

AviUtl2 は Windows 専用の編集ソフトで、コミュニティのスクリプトが数多くあります。Motolii は、その Lua と HLSL のスクリプトをそのまま動かします。HLSL は WGSL に変換します。棚には170以上のパッケージがあります。

限界：Windows の DLL が要るスクリプトは動きません。それ以外でも、すべてが正しく動くわけではありません。動く数は[仕様](specifications.ja.md#対応形式と動作状況)にあります。

## 関係：1本のスクリプトで、複数のレイヤーをまとめて動かす

レイヤーを複数選んで「関係」を当てます。関係は、選んだレイヤーをすべて同時に見て、まとめて動かす短いスクリプトです。Around・Row・Follow・Push は内蔵で、棚にはあと9つあります。スクリプトからは `d3-force` の物理のような力（衝突・引き寄せ）も呼べ、前のフレームでの結果も読めます。

限界：これはスクリプトであり、ノードをつなぐ方式ではありません。ドラッグで2つの値を結ぶ操作は、Motolii にはまだありません。

## 見た目の近さで並べた、エフェクトの地図

エフェクトの棚を地図表示にすると、似たエフェクトが近くに並びます。1つを押すと、近い順に一覧が出ます。フォントの棚にも、書体の同じ地図があります。

限界：配置には、アプリに同梱していない画像モデルを使います。`engine/deps/likeness_models.py` を一度走らせて取り寄せてください。それまでは、色だけの粗い近さで並びます。

## ほかに

- 色の棚は、写真から配色を取れます。
- イージングのカードは、モディファイアのように重ねられ、1つの式として保存されます。
- スキン：テーマのファイルを入れたフォルダで、アプリの色・大きさ・部品が変わります。6つが同梱されています。

## 試す前に

- **Apple Silicon の Mac だけ。** Windows と Linux はビルドしていません。
- **配布用アプリはありません。** ソースからビルドします（Xcode・Homebrew・Flutter、約10 GB、何も無い状態から1〜2時間）。ビルドした Mac でしか動きません。手順は [README](../../README.ja.md#ビルドして動かす)。
- **開発途中です。** リリースはまだありません。プリセットは保存できず、MIDI の音には対応していません。
- **知っている不具合。** コピーでできたレイヤーに画面エフェクト（`.wgsl`）を当てると、絵が崩れます。
- **いま落ちている検査があります。** テストの記録に載っています：[docs/TESTING.md](../TESTING.md)。
