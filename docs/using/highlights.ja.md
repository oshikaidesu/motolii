# Motolii の特長

[English](highlights.md)

Motolii は、MV やモーショングラフィックスを作るためのオープンソースの動画編集ソフトです。ネットで見つけた表現を、プラグインが作られるのを待たずに、すぐ自分の映像に使えることを目指しています。

このページは、いま Motolii でできて、他では手に入れにくいことと、それぞれの限界をまとめたものです。他の編集ソフトとの比較は[ガイド](guide.ja.md#他のソフトとの違い)にあります。まだ整っていないことは[試す前に](#試す前に)にあります。

## AI に頼むと、レイヤーの式とエフェクトを書いてくれる

レイヤーを選んで、やりたいことを自分の言葉で Agent パネルに書くと、エージェントがそのレイヤーの After Effects 式や ISF エフェクトを書き、保存した瞬間に絵が変わります。新しい動きや効果は新しいカードとして足され、すでにあるコードは頼んだ時だけ書き換えます。エージェントには、選んだレイヤーのインスペクターのカードと今の値、各カードのコード、After Effects のリファレンスが渡ります。

使えるのは ACP（Agent Client Protocol）のレジストリにあるエージェント（Zed や JetBrains が読むのと同じ一覧）。どれも同じように動き、モデル・effort・モードも選べます。

限界：エージェントは別のプログラム（`npx`・`uvx` などで起動）で、初回はサインインが要ることがあります。書いたコードが一度で正しく動くとは限りません。

## シェーダーのファイルをフォルダに置くだけで使える

ISF（`.fs`）と WGSL（`.wgsl`）のファイルは、エフェクトのフォルダに置くと、アプリを再起動せずにエフェクト一覧に出ます。タイルには、そのエフェクト自身の動く絵が付きます。インストールも変換も要りません。

棚にはすでに、`.fs` が420本、`.wgsl` が273本あります。自分のファイルの足し方は [shelves/README.md](../../shelves/README.md) にあります。

限界：ISF は VJ ソフトも読む公開の形式です。新しいのは、タイムラインと MP4 の書き出しを持つ編集ソフトの中で使えることです。対応形式のファイルでも、すべてが正しく動くわけではありません。

## エフェクトは全部ファイル

ぼかし、ドロップシャドウ、デュオトーン、グラデーションマップも、ほかと同じ棚のファイルです。エフェクト一覧に、アプリに組み込まれた物はありません。置いたファイルは、これらと同じ扱いで、どれも開いて作りを見ることも、写して直すこともできます。

## クリエイティブコーディングのコードを貼ると、レイヤーになる

スケッチを貼ると、Motolii がどのサイトのコードかを見分けます。Shadertoy、GLSL Sandbox、Hydra、three.js、Two.js、Turtletoy、Paper.js、canvas、Bonzomatic、twigl、Dwitter、tixy を読み、それ以外は p5.js として扱います。p5.js はブラウザなしで動き、コードはレイヤーの上で編集できます。

p5.js では、描画の行ごとに 0 から 1 の強さのスライダーが付き、キーフレームも打てます。

限界：貼った作品が正しく動かない、または動かないことがあります。測った数と知っている不具合は[仕様](specifications.ja.md#対応形式と動作状況)にあります。棚の作品の多くは非営利のライセンスです。公開する物のライセンスを確かめてください。

## Mac で AviUtl2 のスクリプトを動かす

AviUtl2 は Windows 専用の編集ソフトで、コミュニティのスクリプトが数多くあります。Motolii は、その Lua と HLSL のスクリプトをそのまま動かします。HLSL は WGSL に変換します。棚には180のパッケージがあります。

限界：Windows の DLL が要るスクリプトは動きません。それ以外でも、すべてが正しく動くわけではありません。動く数は[仕様](specifications.ja.md#対応形式と動作状況)にあります。

## エクスプレッションカード：式も、まとめ動きも、同じカード

After Effects の式（`wiggle(2, 50)`、`thisComp…`）を貼ると、そのレイヤーに 1 枚のカードとして付き、つまみがインスペクターに出ます。1 行目の `// --property:position`（または `rotation`・`scale`・`opacity`）で、どの値に掛かるかが決まります。

同じ式ファミリーで、コピーや文字を 1 つずつ動かす `each`、複数のレイヤーをまとめて動かす `relate`・`force` も書けます。まとめ動きは、グループか複数レイヤーを選んでタイルを押すだけ。選んだレイヤーをすべて同時に見て動かし、`d3-force` の物理のような力（衝突・引き寄せ）も呼べ、前のフレームの結果も読めます。棚には式が21本、まとめ動きが17本（Around・Follow・Row・Push・Move in ほか）あります。

これらのコードは、上の Agent パネルから AI に書いてもらうこともできます。

限界：これはスクリプトであり、ノードをつなぐ方式ではありません。ドラッグで2つの値を結ぶ操作は、Motolii にはまだありません。

## イージングは区間に付けて、重ねられる

イージングは、キーフレームとキーフレームの間（区間）に付くカードです。タイムラインで区間の線を押して選び、カーブを差し替えます。キーフレーム自体には焼き込まれないので、当てたあとでもいくらでも変えられます（プリセットを当てた瞬間にキーフレームが固定されて直しづらい、ということがありません）。

カードはモディファイアのように重ねられます（通す・掛ける・足す）。重ねた曲線は焼き固めずそのまま正確に評価され、1 つの式として保存されます。

## 見た目の近さで並べた、エフェクトの地図

エフェクトの棚を地図表示にすると、似たエフェクトが近くに並びます。1つを押すと、近い順に一覧が出ます。フォントの棚にも、書体の同じ地図があります。

限界：配置には、アプリに同梱していない画像モデルを使います。`engine/deps/likeness_models.py` を一度走らせて取り寄せてください。それまでは、色だけの粗い近さで並びます。

## エフェクトのタイルは、動くサムネイル

棚のエフェクトのタイルは、そのエフェクト自身が動く小さなプレビューです。アプリが各エフェクトを実際に当てて16枚の絵を撮り、効果がいちばんよく出るパラメータを選んで動かし、ちゃんと効いているかまで見ます。だから一覧を眺めるだけで、名前では分からない「何が起きるか」が分かります。

この「どのパラメータがよく効くか」の重みは、インスペクターの色にも使われます（下）。

## グループレイヤーで、入れ子にまとめる

レイヤーはグループにまとめられ、グループの中にグループも置けます。タイムラインの三角で開け閉めし、閉じれば1行、開ければ中のレイヤーが並びます（Apple Motion と同じ）。グループ自身のキーフレームも、その1行についていきます。

## インスペクターの値はカード。効くパラメータほど色づく

インスペクターの値は、置いたエフェクトと同じカードで描かれます。1つのパラメータは、名前・操作・小さなプレビューを1枚のブロックに収めるので、ラベルだけの行や空いた1行で縦に伸びません。色は3つの数値を1つの色として1枚にまとめます（白い色が数値欄を3つ食う、ということがありません）。

パラメータには「結果をどれだけ動かすか」の重み（上のサムネイルと同じ重み）が付き、よく効くものほどブロックが色づきます。色は効きの強さの段階で、青磁・撫子・浅黄。はい／いいえではなく、濃淡で主要さが読めます。

## ほかに

- 色の棚は、写真から配色を取れます。
- スキン：テーマのファイルを入れたフォルダで、アプリの色・大きさ・部品が変わります。6つが同梱されています。

## 試す前に

- **確かめたのは Apple Silicon の Mac だけです**（M4、macOS 15.5）。Windows と Linux はまだ試していません。
- **配布用アプリはありません。** ソースからビルドします（Xcode・Homebrew・Flutter、約10 GB、何も無い状態から1〜2時間）。ビルドした Mac でしか動きません。手順は [README](../../README.ja.md#ビルドして動かす)。
- **開発途中です。** リリースはまだありません。プリセットは保存できず、MIDI の音には対応していません。
