# グループの「関係」— 手引き（11/6）

考え（ユーザー 11/6）：
「たくさんあっても、1 つの時と同じ手で動かせる。新しく覚えるのは『どの順で』だけ。それは並んでる絵を触って決める」。

文字のアニメーター、クローナーのエフェクター。外の道具では、この「順に動く」は文字かコピーの中に閉じている。
Motolii はその「動き」だけを取り出して、メンバーのある物ならどれにでも掛ける。それが「関係（Relation）」。

太字が、使う人に読ませる手引き。その下の「なぜ」は、考えから言える理由。考えから言えない物は載せない。
第三者の批評（厳しめ、3 回）で落ちた物は直すか、下の「まだ」に理由ごと置いた。

---

## 1. グループを作る

**物を 2 つ以上選ぶと、舞台の上に「Group」が出る。押すとグループになる（⌘G、メニューの Group と同じ）。**

- なぜ舞台の上：物を選んだ時、人は舞台を見ている。そこに「選んだ物でできること」が並ぶ。メニューと ⌘G だけでは、知っている人しか見つけられない。
- なぜ Group が最初：たくさんを 1 つの手で動かすには、その「1 つ」が要る。他の札（Around、Row、Follow、Push、Move in）は選んだ物を結ぶ別の動きで、グループの前に要る物ではない。
- グループは 1 つの物として選べて、1 つの物として Transform を持つ。

**文字は、2 文字以上あれば最初から Relation の札がある。その Split で、文字ごと（Letters）か単語ごと（Words）に分けると、それがメンバーになる。**

- なぜ Split が Relation の中：Type の札（斜体、折り返し）にあった時、ゴルフの採点役は順番を Split の近くに探した。理由はそれだけ（「誰がメンバーか」は、コピーなら Copies の札、グループなら層で決まり、文字だけが札に持つ。同じ話とは言えない：3 回目の批評）。

**コピーを増やす（Copies の How many）と、コピーがメンバーになる。**

- なぜ 3 つとも同じ：関係は「メンバーどうし」の話なので、メンバーが何でできているかは問わない。3 つとも、同じ札、同じ言葉、同じ図になる。

## 2. 関係の札

**メンバーが 2 つ以上ある物を選ぶと、Inspector の Transform のすぐ下に「Relation」の札が出る。**

- なぜ名前が Relation（関係）：ユーザーが決めた名前。中身は「メンバーどうしが、どの順で動くか」で、コピーの話でも、文字の話でもない。だから Copies や Type の札には置かない。
  - 同じ名前で別の物が無いように、選んだ物を結ぶ関係のうち、ファイルで書いた関係の札は「Strength」、Move in の札は「Move in」に変えた（前は「Relation」「Group」で、グループと取り違えた）。
- なぜ 2 つ以上：順番は 2 つ以上で初めてある。
- なぜ Transform のすぐ下：順に配られるのは、Transform の手（位置、回転、大きさ、不透明度）。手のすぐ下にあれば、上から「この手が、この順で配られる」と読める。
- グループのメンバーは、そのグループがじかに持つ物。グループの中のグループは 1 つのメンバーで、そのグループ自身にも順番があれば、遅れは足される。
- グループには Copies、Wave、Field、Scatter の札が出ない。どれも物自身のコピーと文字を動かす物で、グループのメンバーには効かない。効かない札は見せない。

## 3. 動かす：1 つの時と同じ手で

**グループの Transform（位置、回転、大きさ、不透明度）にキーを打つ。または、棚のモーション（Fade In など）をグループに落とす。**

- なぜ：新しく覚える物を増やさない。グループを動かすのは、1 つの物を動かすのと同じ。
- 順に配られるのは Transform と不透明度だけ。色や文字の中身は、全員いっしょに変わる。
- 関係が Together（順番なし）の時は、メンバーが全員いっしょにその動きをする。
- **回転と大きさは、グループの中心（文字なら文字全体の中心）のまわりで、メンバーが順になぞる。** 1 つずつその場で回ったり育ったりはしない。コピーだけは大きさがその場で育つ（コピーの間隔は大きさで広がらないため）。
  - なぜこう書く：「その場で 1 つずつ」にするには、キーのどこが「止まっている形」かを決める必要があり、それは考えからまだ言えない（下の「まだ」）。言えない物を作らず、今の動きをそのまま書く。
- 棚のモーションを落とすと、キー 2 つとイーズが足される。自分で決めた順番は変わらない。
  - なぜ：モーションは「手」の見本。順番は使う人が決めた物なので、見本が上書きしない。
  - 順番がまだ無い時は、見本の順番と間隔が入る（見本の見た目の一部なので）。
  - 名前が順番そのもののモーション（Random Fade In、Random Fade Out）は、いつもその順番を入れる。名前が約束しているから。

## 4. 図を読む

**Relation の札には、メンバーが今の並びのまま点で描かれる。先に動く物ほど明るい。始まる場所に十字。図はいつも高さ 72。**

- なぜ並びのまま：順番は「どこから」の話なので、並んでいる絵が要る。
- なぜ明るさ：順番は「どれが先か」という順序で、明るさは目で順序を読める。平たい並びでは、先に動く物ほど大きくもする（大きさも順序を読める）。
- 奥行きのある並びでは大きさを変えない。斜めに描いた奥行きでは、大きい点は「手前」に読めてしまう。
- なぜいつも同じ高さ：図はこの札のただ 1 つの新しい物。前は普段 24 で、手を乗せると 72 に伸びて再生し直した。24 では「小さな線」にしか見えず、伸びると下の札が動き、再生で点が消えた（ゴルフ (g1)(g9)）。読もうとした時に絵が動かないように、72 のまま動かさない。順番が変わった時だけ 1 回再生する。
- **左上の名前は、今の順番を読んで付く：From the first、the last、the middle、the ends、this one、here。逆向きなら Toward。**
  - なぜ：Anchor の札と同じ。Anchor は点を置くと名前が付き、どれにも当たらなければ Custom。名前が値を決めるのではなく、値に名前が付く。

## 5. 順番を決める

**図の上を押すと、そこが始まる場所になる。メンバーの上でも、間でも、外でもいい。押したまま動かせば、離した所。**

- なぜ：「ここから」を指で指す。考えの「並んでる絵を触って決める」そのもの。
- なぜどこにでも置ける：Anchor の点と同じ手（Anchor はどこにでも置け、9 つの点から選ぶ形は「一歩後ろ」と書いてある）。前は押すと必ずいちばん近いメンバーに吸い付いた。それは「何番目のコピーから」というコピーの考え方で、考えからは言えなかった（3 回目の批評）。
- メンバーと真ん中の近く（8 点以内）では吸い付く。
  - なぜ：平らな図では奥行きを言えない。メンバーの上なら、その物の奥行きをそのまま使える。真ん中は Anchor の Centre と同じく、いちばん使う場所。
- 置いた場所は場所として覚える。メンバーを足すと、その場所に近い物から始まる。

**By で数え方を選ぶ：place（場所からの距離で、近い物から）、order（並びの順で、場所にいちばん近いメンバーから）、random（ばらばら）。**

- なぜ place：場所から近い順は、メンバーが何でできていても同じに言える。初めて押した時（まだ Together の時、random の時）は place になる。
- なぜ order も要る：場所では言えない順がある。
  - 2 行の文字を打つ順。距離で数えると、2 行目の頭が 1 行目の終わりより先に出る。
  - 輪になったコピーを 1 周する順。距離で数えると、両側から回って向こう側で会う。
  - 文字は読まれ、コピーは数えられる。その物自身の順がある時のための数え方。選んで作ったグループは、文字と同じく読む：上の行から、行の中は左から。前後に重なる物は手前から。行の高さは舞台の 1/10（Move in と同じ読み方）。
  - order では、押すといちばん近いメンバーに吸い付く。並びの順には、メンバーの間（半分）しか無いから。
- なぜ random：考えからは言えない。理由は目的（ネットで見る「ばらばらに出る」表現をすぐ使う）と、名前が約束している棚のモーション（Random Fade In）。
- 棚のモーションが入れる順は order で、最初のメンバーから。

## 6. どれだけずらすか

**First to last（秒）：最初のメンバーが動き出してから、最後のメンバーが動き出すまで。0 なら Together。マイナスなら逆：遠い物から、場所に向かって。**

- なぜ全体の幅：メンバーを増やしても、全体の長さが変わらない。文字を足しても、タイトルが出終わるまでの長さは同じ。
- なぜ名前を Delay から変えた：Delay は「1 つずつの遅れ」に読めた（ゴルフ (g4)）。
- なぜマイナス：逆の順を言葉（end、edges）で持たない。Transform の大きさがマイナスで裏返るのと同じ。
  - 端から真ん中へ（前の edges）＝真ん中に置いてマイナス。
  - 終わりから（前の end）＝最後のメンバーに置く。
- 場所がどのメンバーからも離れていても、最初のメンバーは 0 秒で動き出す。
  - なぜ：名前の First to last が「最初が動いてから」と言っているから。距離は「いちばん近い物」から「いちばん遠い物」までで割る（GSAP の distribute と同じ割り方）。
- 初めて順番を付けた時（Together の時に図を押す、By を選ぶ）は、キーの長さが入る。最初のメンバーが着く時に、最後のメンバーが動き出す。
  - なぜ：どの数のメンバーでも「順に動いた」と見える。前の 0.5 秒きめ打ちは、100 のメンバーで 1 つ 5 ミリ秒になり、いっしょに見えた。
  - キーがまだ無い時は 0.5 秒。図に順番を見せるための仮の値で、キーを打てば動く。

## 無くした物と、その理由

| 無くした | 理由 |
|---|---|
| Copies の札にあった順番と図 | 割った文字はコピーではない。グループのメンバーもコピーではない。置き場の理由が「コードの空き枠」しか無かった |
| 割った文字に Copies の札を出す | 順番を運ぶためだけに出ていた。文字に How many は効かない |
| 撫でる（向きで From を決める） | 出典も無く、2 回のゴルフで 1 度も使われなかった。手引きで意味を言えない |
| 振る（ばらばらに振り直す） | 同上。しかも振り直すと Scatter の並びまで変わった |
| ダブルクリックで Together | 同上。Together は First to last の 0 |
| 十字を掴んで点の間に置く | 押す・なぞるで同じ事ができ、「間」は図の上では選べない。「From this one」と言えるのは物の上だけ |
| 図が手の下で 24 → 72 に伸びる、手を乗せると再生 | 読もうとした時に絵が動く |
| 0.5 秒きめ打ちの初めの間隔 | メンバーの数で潰れる |
| From の言葉 start、centre、end、edges | 場所とマイナスで言える。しかも言葉は「何番目」で、図は「距離」で数えていたのに、同じ From に入っていた。どれも GSAP の stagger の from を Copies の札からそのまま持ってきた物（3 回目の批評）。古いファイルと棚のモーションのために、読みはする |
| point という言葉 | 場所そのものが値になった（place） |
| 押すと必ずメンバーに吸い付く | 「何番目のコピーから」の考え方。Anchor の点はどこにでも置ける |
| 「From this one」という名前 | 場所で覚えているので、メンバーを足すと嘘になる。名前は値を読んで付ける |
| 場所が離れていると、最初のメンバーが遅れて動き出す | First to last が嘘になる |

## まだ決めていない物（手引きに載せない）

| まだ | なぜまだか |
|---|---|
| 回転と大きさを、メンバーが 1 つずつその場でする | 1 つの物が回る・育つのと同じにするには、キーのどこが止まっている形かが要る（In なら最後、Out なら最初）。手で打ったキーにはそれが無い。決めずに作ると、順番を付け外しするだけで止まった絵が変わる |
| Move in（選んだ物が順に入ってくる、今の札） | グループ＋モーション＋関係と同じ事をしている。けれど Move in は x、y、回転、大きさ、不透明度、散らしを 1 つの札で持ち、棚のモーションはまだ 1 つの値だけ。全部できるまで消さない |
| Around、Row、Follow、Push を関係の札に合流させる | 持ち主のノート §9「3 つの窓の設計を 1 枚に」。今は選んだ物から別の物（behaviour）として作られる |
| random の並びが Scatter と seed を分け合う | 振るを無くしたので、今は Seed を変えた時だけ。変えると Scatter も変わる |
| 値の行に「順に動く」と出す印 | キーを打った値が、なぜ順に動いたかが見える。持ち主のノート §9 |
| 点でなく、メンバーそのものの形で描く | 文字の L を数えずに押せる |
| In と Out で逆の順 | 持ち主のノート §10。今は別のグループに入れ直す |
| 複数選んだだけで Relation を出す（グループを作らずに） | 第三者の提案（3 回目）。ゴルフ 1 人目は「全部選んで、Inspector か右クリックで stagger を探す」と言った。けれど持ち主が決めた流れは「選ぶ→グループ→関係」で、順番を触っただけで層の形が変わるのは驚く。2 人目以降のゴルフで迷えば考え直す |
| タイムラインのバーに、メンバーの遅れを描く | ゴルフ 1 人目は順番をバーの頭で作った。バーと関係の図が別々の絵にならないように |
| 場所を数字（x、y、z）でも打つ | Anchor には数字の行がある。今は図でしか置けない |
